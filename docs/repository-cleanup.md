# 仓库专项整治条例

本条例用于开源前清理，也作为后续贡献的维护规则。目标是让当前分支只保留运行、开发、验证和维护所需的内容；历史过程交由 Git 历史保存。本轮不修改发布版本，不发布制品，不重写 Git 历史。

## 条例

1. **先确认归属。** 以 `git status --short --branch` 建立基线，保留已有工作区修改和未跟踪文件。仅清理本次确认无用的仓库内容，不清除个人配置、本地数据或凭据。
2. **凭调用证据删除代码。** 从桌面入口、MCP、preload、Renderer、脚本和测试核对引用，区分生产路径、升级恢复路径、测试工具和真正死代码。不能只凭名称含有 `old`、`legacy`、`v1` 或 `v2` 判断。
3. **收敛过渡入口。** 删除迁移结束后多余的开发命令、别名和占位代码，同步更新相关文档及测试。已删除旧入口的禁止回归检查和打包排除规则必须保留。
4. **删除无用前端库存。** 移除没有实际使用者的组件、导入、局部变量和样式；不为保留组件库存而制造业务引用。仍使用的组件保留必要的组合接口和可访问性支持。
5. **合并当前文档。** 删除已过时的方案、阶段交付报告、静态原型和重复旧版本说明。当前行为归入 README、产品边界、架构及验证说明；持续维护的安全设计决定保留明确依据。
6. **保持版本与依赖可追溯。** 保留 `CHANGELOG.md`、许可证、发布校验、锁文件和有回归覆盖的依赖补丁。只有实际依赖图变化才更新锁文件，不顺带升级依赖或修改产品及兼容标识。
7. **保护安全与升级。** 不改变凭据保管、作用域、连接检查、单次确认、命令/数据库策略、主机指纹及审计边界。旧数据读取、迁移和未完成事务恢复仍有用途，须保留实现及测试。
8. **同步验证。** 删除旧功能时清理仅为旧实现服务的测试，保留当前行为与安全回归覆盖。执行相关定向测试、`corepack pnpm run check`、`corepack pnpm test`；UI 变更运行 `corepack pnpm run test:ui`，打包及 MCP 变更运行构建和打包冒烟。
9. **防止再次积累。** 静态检查应发现未使用声明；维护文档应指向当前代码和命令，不依赖本机截图、临时路径或已删除的阶段报告。
10. **按证据验收。** 复核引用、`git diff --check` 和最终文件清单，确认没有生成物、真实基础设施信息或敏感数据进入变更。明确记录保留项、验证结果和未覆盖范围，不把代码清理等同于完成生产安全审计。

## 保留与安全复核

- `ProjectStore`、旧凭据迁移和 draft 提交事务恢复仍有生产用途；保留实现、回归及用户旧数据。
- `disconnectLegacy` 等仍被当前连接协调器调用的包装继续保留；不得按名称删除。
- `src/mcp.mjs` 和旧 Renderer 的打包排除、缺失断言继续保留，防止退役入口回流。
- 仍被使用的 shadcn 组件保留组合接口，依赖补丁依据迁入 [当前架构](architecture.md)。
- 删除的配置脱敏函数原本没有生产调用；远端配置原文读取契约不变。凭据隔离、作用域、单次确认、文件 stat/hash 校验、主机指纹、命令/数据库策略及审计边界均未修改。

## 本轮验证记录

环境为 Windows x64、Node.js 24.12.0、pnpm 11.21.0。本轮不声称已在 Node.js 22 或远端 CI 复验。

| 检查 | 结果 |

| 后端定向回归 | 221 项通过；日志、SFTP、自动重连及认证失败审计验证当前生产路径 |
| `corepack pnpm run check` | 通过；129 个源码/脚本/测试文件语法及 Renderer 类型、未使用声明检查 |
| `corepack pnpm test` | 636 项通过，失败/取消/跳过均为 0 |
| `corepack pnpm run test:ui:all` | 四组全部通过；包含 31 次只读调用、27 次业务变更、111 次插件请求及 36 次真实管理器验证 |
| `corepack pnpm run dist` | Windows 安装包构建通过；版本未变 |
| `scripts/verify-package.mjs` | 包内源码及 Renderer 与本轮构建一致，源码 Renderer 排除规则通过 |
| `scripts/packaged-mcp-smoke.mjs` | 35 个结构化工具及归档运行时通过 |

测试总数变化来自删除旧项目缩写、旧游标及闲置脱敏器的 11 项专属测试，新增 1 项语法检查器行为测试；仍有用途的日志、传输和重连测试迁至现行实现。首次全量运行发现迁移测试仍断言旧下载结果字段，修正为现行 `bytes` 后已完整重跑通过。

打包 UI 失败时，诊断显示 `document.visibilityState = hidden`、动画帧不推进，Renderer console/exception 记录为空。本地 Sonner 实现会在文档隐藏时暂停通知自动关闭；当前执行环境无法恢复测试窗口可见性。诊断尝试未保留到代码中，没有延长超时、跳过断言或修改生产节流/CSP。该项仍需在可见的 Windows 桌面运行：

```powershell
node scripts/packaged-ui-smoke.cjs "dist/win-unpacked/Agent运维工作台.exe"
```

构建仍提示 Renderer 单块资源较大及使用默认 Electron 图标，本轮未扩大范围处理。未连接真实基础设施，未在当前账户安装、覆盖升级或卸载，未发布安装包。本轮整治不等同于完整发布验收或生产安全审计。
