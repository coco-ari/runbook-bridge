# 操作记录

环境记录、插件记录和项目概览按完整操作展示发起方、具体动作、目标、结果及耗时。环境与插件记录可展开查看开始、人工批准或拒绝、执行结束等过程。用户批准仅表示授权完成；尚未执行时显示「已批准待执行」，执行结果单独判定。

参与方包括用户、Agent、系统和来源未记录。筛选「用户」也会命中用户参与审批的 Agent 操作，主行仍显示原发起方。动作包括日志列举、读取与搜索，文件查找、上传、下载与修改，数据库结构、表预览与只读查询，以及连接、配置和终端或监控会话。

环境、插件记录与项目近期操作默认隐藏桌面用户成功完成的 Redis 键扫描，避免自动分页刷屏。勾选「显示 Redis 扫描」可查看这些记录；失败、拦截、进行中、结果未记录、Agent 扫描及键值读取仍正常展示。历史记录同样适用，原始审计文件不删除、不减少写入。内部操作视图通过布尔参数 `includeRedisScans` 控制，分页游标同时绑定此设置。

## 历史查询与更新

- 搜索动作、目标、插件名称、安全失败原因或错误代码；可按参与方、操作类型、结果及最近 24 小时、7 天、30 天筛选。
- 环境和插件页面每批显示 50 项操作，可继续加载。服务端按记录文件快照分页，追加记录不会导致后续页重复或漏项；清除记录、更换筛选条件或重启应用后旧游标失效，需要刷新。
- 查询使用有界候选窗口，每轮最多处理 4096 行候选事件；对候选操作流式追溯完整过程。范围较大或匹配稀疏时提供「继续查找更早记录」，不会把尚未扫描的部分当成没有记录。内存不随完整历史大小增长，但追溯耗时随文件大小增长；最多同时执行两个查询。
- 查看最新一批且处于列表顶部时自动更新。翻阅历史时显示新记录提示，保留阅读位置。点击「查看最新记录」回到顶部。
- 单项详情保留首次事件及最近 63 个事件，超过时明确显示事件总数和省略提示。原始审计事件仍完整保存在本机。

## 记录与兼容

原始 `operations-v3.jsonl` 保持逐事件追加；操作视图在读取时生成，不改写旧记录。每条新事件带独立 `auditId` 和当前进程的 `auditSessionId`。执行、审批、连接计划和会话分别通过 `operationId`、`confirmationId`、`planId`、`sessionId` 关联；底层命令与连接事件在同作用域内继承父操作的关联信息。重试使用新的执行标识。

只有一组明确开始与结束的旧请求可按 `requestId` 关联。同一旧请求标识出现多个开始或结束事件时保留独立事件，不按时间或路径猜测。新文件传输的续传尝试单独记录。缺少来源、插件名称或最终结果时显示「来源未记录」「插件名称未记录」「结果未记录」，不会据此断言插件已删除或操作失败。只有当前进程仍持有执行状态时显示「进行中」；旧开始事件不能证明操作仍在运行。

桌面内部 `listAudit` 增加 `view: "operations"`，支持 `actor`、`category`、`result`、`query`、`from`、`to`、`cursor`、`limit`。操作视图返回安全的结构化摘要、参与方、状态和过程。游标签名绑定当前筛选与作用域，不能跨项目、环境或插件复用。原始事件读取契约仍供内部兼容使用；没有新增 MCP 工具。

## 数据边界

动作摘要按操作类型提取允许的元数据。数据库查询额外记录从安全解析器提取的表名、返回行数及截断状态；Shell 摘要仅保留常见命令、受限选项与资源目标，自定义命令、脚本和其他参数隐藏。审批记录使用独立安全摘要，不直接持久化审批页面的命令或文件内容摘要。SQL 正文、查询参数、数据库行、Redis 值、终端输入输出、文件正文和远端错误正文不会被新增摘要保存或返回。

人工终端在当前 Bash、Zsh 会话安装临时提示钩子，返回提示符后逐项记录命令的保守摘要及退出码；不会修改启动文件或历史策略，也不会保存按键、密码输入和命令输出。新开终端会话后生效。Shell 未提供历史内容时仅记录交互活动且不猜测命令；子 Shell、编辑器、交互程序内部输入以及断连前尚未完成的命令不作为逐条命令回报。终端会提示当前记录能力及写入失败。旧记录无法补出当时未保存的命令。已有审批绑定、作用域校验和执行门禁继续在原入口执行。
