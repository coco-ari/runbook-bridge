# MySQL 共享连接与数据库管理

MySQL 使用“连接 → 数据库”模型。环境内的连接保存一次地址、账号、凭据、隧道和 TLS 配置；每个数据库保留自己的插件标识、库名、名称、Agent 权限与限额。运行时仍按数据库建立独立连接，不能通过共享配置改变查询范围。

## 使用

1. 新增插件时选择 MySQL，填写连接信息，点击「读取数据库」。选择一个库按单库展示，选择多个库按数据库组展示。读取列表不自动授权其他数据库。
2. 已有单库可以打开连接编辑，在「管理数据库」中读取并勾选更多库。原插件及其权限保持不变，只为新增数据库创建新节点。
3. 数据库组与普通插件使用一致的两行样式，名称旁显示库数量，下方显示连接状态；展开后用缩进与细线表示成员归属。组头右侧可一键连接全部、连接剩余或断开全部，收起时也可操作；「更多」菜单提供「管理连接」及整组连接、断开操作。连接操作只包含本连接的成员及连接所需的同环境 Server 隧道依赖；断开数据库组保留共用 Server。每个库分别显示真实状态，部分失败不会伪装成全部成功。
4. 编辑共享连接会暂停组内连接，等待正在执行的操作结束；有未提交 SQL 事务时拒绝配置修改。保存或取消后只尝试恢复原来已连接的成员，新增加的库需主动连接。
5. 「管理数据库」中取消勾选表示移出当前连接，保留原单库插件和原连接配置，不删除数据库或插件。剩下一个成员时自动恢复单库展示。右键插件可「删除插件」；数据库组「更多」菜单可「删除整组」，确认框列出全部受影响成员。两种删除都只移除客户端配置，不删除 MySQL 数据库或表数据。
6. 数据库名称固定绑定节点。需要其他库时增减关联，不能直接把旧节点改指向另一个库。业务名称、说明和 Agent 限制仍可分别编辑；环境运维说明可记录正式库、测试库等用途。

## 存储与凭据

环境文件使用 schema 2，`mysqlConnections` 保存环境内的连接记录，每条含 `connectionId`、名称、版本及公共连接字段。数据库文件使用 schema 2，仅保存 `mysqlConnectionId`、`target.database` 和各自的元数据、权限、限额。其他插件继续使用原模型。

WorkspaceStore 读取数据库节点时在同一环境内解析连接引用，为原运行时提供完整的配置投影；公共字段不会重复写回各个数据库文件。编辑会话绑定全部成员和连接版本，成员或配置变化后拒绝陈旧保存。

凭据库按 `projectId/environmentId/mysql-connection-<UUID>` 保存一份加密凭据，绑定连接身份、地址、账号、隧道和 TLS。不会将密码写入环境、数据库 YAML、MCP 结果或日志。修改公共配置、凭据与成员使用同一加密事务；失败完整回滚，启动时恢复中断事务，遇到第三种状态则保留现场并隔离项目。

保存时默认合并已有凭据，保留未重新输入的历史字段。旧凭据因绑定不一致或解密失败而不可读时，输入新凭据后须明确确认替换；替换与整组配置使用同一事务，失败恢复原配置和密文。确认期间恢复可读的字段仍会保留，系统加密不可用或凭据库结构损坏不能绕过。需要同时移出数据库时，应先保留全部成员完成凭据恢复，再取消关联，避免改变移出成员原有的认证配置。

整组删除通过桌面接口 `deleteMysqlConnection` 提交，绑定确认时的连接标识、版本及全部成员标识和版本；成员新增、移出或配置修改后要求重新确认。环境索引、共享连接与成员配置使用同一事务删除，失败全部回滚。运行中的 SQL 事务和连接编辑会话继续阻止删除；成功后逐个清理目标成员连接、失效 Agent 上下文并记录审计，保留其他组及共用 Server 隧道。凭据沿用单插件删除的保留策略。此接口不向 MCP 开放。

## 升级与云同步

首次启动先恢复旧事务，再自动迁移现有 MySQL 配置。迁移保留原插件标识、固定库、业务信息、权限、限额和凭据，不连接真实基础设施。

- 普通旧单库分别迁移为独立连接，不根据相同地址自动合并。
- 上一版标签分组中，只有公共配置与凭据均相同的成员共享连接；存在差异的成员保留各自配置，拆为独立连接。
- 上一轮多库实验配置按明确勾选的数据库拆成独立节点，默认库保留原插件标识。默认库不在授权范围、超过环境容量或存在标识冲突时停止迁移并保留原配置。
- 加密备份保存在数据目录 `runtime/plugin-batches/backups/`；未完成事务保存在相邻 `transactions/`。正常重复启动不会重复迁移。无法解密原凭据时不覆盖它们，项目暂时隔离。
- 从本机备份恢复旧单库配置时，也会在恢复事务中完成转换，无需再次重启。

新云快照使用 schema 5：连接配置和凭据只传输一份，数据库节点通过连接标识引用它。旧云快照仍可读取和导入，导入后转换为新模型；历史、加密与条件提交继续保留。所有设备应安装新版，旧版不支持读写新格式。应用不会自动上传迁移后的本机配置，仍由用户执行云同步。

## MCP 与效率

MCP 工具数量和参数不变。Agent 使用每个数据库的 `pluginInstanceId`，只允许该固定库内策略批准的单条 `SELECT` / `EXPLAIN SELECT`。共享连接不提供跨库查询或写入权限，不预加载各库表结构；表结构和数据继续按需读取。
