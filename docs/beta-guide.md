# 测试版说明与已知限制

[返回首页](../README.md) · [首次使用](getting-started.md)

当前公开测试目标是 Windows 10/11 x64 上的个人开发和小团队排障。建议先用测试环境完成连接、只读检查和少量人工编辑，确认符合自己的使用要求后再扩大范围。自动化通过不代表所有远端版本、VPN、代理和长期运行场景都已验证。

## 升级与备份

1. 完全退出桌面应用，避免复制正在写入的数据。
2. 备份 `%LOCALAPPDATA%\AIOpsTool` 整个目录；设置了 `AI_OPS_DATA_DIR` 时备份对应自定义目录。
3. 安装新版本。测试版与稳定版共用身份和安装位置，不是两套并行安装。
4. 启动后核对项目配置，重新连接测试环境，再恢复日常使用。

本地备份含敏感配置和加密凭据，应妥善保存，不上传 Issue。凭据与操作系统用户绑定，复制目录不保证能跨用户或跨平台解密。跨大版本降级尚未保证；不要用旧版本直接写入唯一一份新版本数据。恢复时应退出应用，并配套使用备份时的软件版本和数据副本。

## 能力边界

| 功能 | 当前限制 |
| --- | --- |
| MySQL | 固定单库；SQL 编辑器只执行策略允许的单条只读查询；人工行编辑要求有完整主键的 InnoDB 单表，不支持关联结果、视图和无主键写入 |
| MySQL 新增／删除 | 存在相关触发器或受限制的级联关系时会阻止操作；结构、并发状态或约束校验失败时整批回滚 |
| Redis | 支持 String/JSON 新增编辑，以及 String、Hash、List、Set、ZSet 的单 Key 删除；不支持 Hash 字段编辑和通配符批量删除 |
| Redis 内容 | 二进制、超限或未完整读取的值不能编辑；访问受配置 Key 范围限制 |
| 草稿与弱网 | 草稿仅在当前会话内；关闭应用不恢复。提交结果不确定时禁止重复保存，需核实状态；断线后保留草稿，重连需要重新核对 |
| 文件传输 | 单文件有大小和并发限制；不支持整目录上传，下载暂不支持断点续传；上传恢复受会话、时间和次数限制 |
| Docker | 当前容器工作区只读 |
| macOS | 有源码构建及测试入口，终端审计回归仍有失败；尚未提供已签名、公证的正式安装包 |
| Windows 分发 | 当前安装包未进行发布者数字签名，系统可能提示未知发布者；提供 SHA-256 供校验 |

更详细的条件见 [MySQL 编辑](mysql-data-editing.md)、[Redis 工作区](redis-workspace-design.md)、[文件传输](desktop-file-transfers.md)。

## Agent 和数据

- 首次连接由用户发起；Agent 无法接管人工终端。
- Agent 的 MySQL/Redis 工具保持只读。Agent 的文件变更、服务控制、Shell 按相应流程确认；人工终端按登录账号权限执行。
- 应用管理的凭据不返回给 Agent；远端日志、配置、文件和查询结果可能含未脱敏业务信息，并由所用 AI 客户端处理。本地桌面不等于所有业务数据都不会离开本机。
- 对 AI 给出的结论和建议应核对证据，不能把模型输出当成操作授权。[安全说明](../SECURITY.md)

## 如何反馈

请报告版本及构建标识、操作系统、连接方式、复现步骤、预期结果和实际结果。遇到保存问题，请说明界面显示“成功”“失败”还是“结果待核实”，不要反复执行来尝试复现。

公开反馈需移除密码、私钥、Token、真实地址、业务数据和客户名称。漏洞按[安全政策](../SECURITY.md)私下报告；普通问题使用 [Issue 模板](https://github.com/coco-ari/runbook-bridge/issues/new/choose)。
