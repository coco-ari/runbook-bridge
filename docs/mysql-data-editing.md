# MySQL 桌面数据编辑方案

## 目标与交互
同时支持表数据预览和简单单表 SQL 查询结果。桌面用户直接在查询结果中双击单元格修改，始终使用同一张表格，不切换布局、列宽、行高或滚动位置；行首复选框、行号拖选与 Shift 连选用于选行；批量赋值明确选择字段和统一的新值。逐格修改与批量赋值都先暂存，显示修改高亮、已选行数和待保存数量；点击底栏「保存」即提交，无二次确认弹窗。保留复制、行详情、键盘操作、长文本编辑、空字符串与 NULL 区分。草稿仅在当前应用会话内保留。

## 可编辑条件
后端验证单条 SELECT、唯一基础表、完整主键和直接字段映射；允许 WHERE、ORDER BY、LIMIT 和表/字段别名。JOIN、聚合、DISTINCT、UNION、子查询、计算列、视图和无主键结果返回明确的只读原因。复合主键全部参与定位，主键及生成列不可改。第一版支持 InnoDB 事务表和常用标量字段；二进制及无法无损表示的字段保持只读。数据库账号需要 UPDATE 权限，不自动提权。

## 安全设计扩展
新增只允许当前桌面主框架访问的编辑 API，按窗口、项目、环境、插件、配置版本和实际连接会话绑定。Agent/MCP 原有单库只读能力保持不变，不新增任意写 SQL 接口。
首次双击或批量赋值时读取无损数据，后端保留有界的原值快照与随机行标识。前端按完整主键匹配当前显示行，不按行号匹配；字段值已变化、主键不完整或无法无损核对时拒绝编辑；前端只能提交行标识、允许编辑的字段和新值，不能指定主键条件或目的数据库。
点击保存即授权当前暂存修改，内部先生成短时一次性保存计划，绑定完整规范化变更。提交只使用计划中保存的参数。最多每批 100 行、有限字段字节；过期、重连、跨窗口及配置变化拒绝提交。
整个事务占用现有每插件串行调度名额；在同一数据库连接中锁定选中的真实主键行，比较原值并复查元数据，全部通过后逐行更新，验证写入结果再 COMMIT。冲突、删除、字段变更、约束错误整批回滚。提交阶段断连标记结果不确定，不自动重试。重复提交同一计划只返回已有状态。
操作记录保存用户、库表、字段名称、行数、结果与安全错误代码，不保存业务原值、新值、SQL 参数或凭据。

## 生命周期与体验
字段核对、暂存和保存分别有明确状态；保存期间禁止重复点击与修改目标。刷新或关闭含草稿的标签时显示保留/放弃选择，切换标签保留草稿。冲突定位到对应行并保留草稿供用户检查；连接失效的快照必须重新加载。保存成功显示结果并更新表格；提交结果不确定时明确说明并要求核实数据。
页面沿用现有 React/Radix、主题和紧凑表格布局，不增加新的表格依赖。仅首次需要编辑快照时读取数据库，不在键入时查询数据库，不把所有单元格常驻为输入框。

## 实施阶段与证据
1. 后端策略、无损类型、快照/确认计划、事务写入及单元测试。
2. 两入口共享原位编辑、批量赋值、单次点击保存、草稿生命周期、操作记录。
3. 在用户授权测试机建立独立随机名称测试库，使用合成表验证修改、并发删除/修改、复合主键、数值精度、事务回滚和断线场景。测试删除用于验证并发与清理，不新增表格删除按钮。
4. UI 自动化验证实际输入、多选、键盘、批量修改、冲突反馈、明暗主题及窗口布局；检查真实渲染截图。
5. 运行 check、完整测试、相关 UI 测试、打包与正式包验证；审查源码差异和敏感信息，提交推送并提供新安装包。

## 使用步骤

1. 在表预览执行筛选，或在 SQL 标签执行简单单表 SELECT（包含完整主键）。
2. 双击需要修改的单元格，在原位置输入；首次编辑会核对单表、主键和原值。不符合条件时显示只读原因。数据表不切换视图，筛选、排序、列宽及滚动位置保持。
3. 修改先暂存，未点击保存前不写入数据库；Enter 暂存并移到下一行，Tab 移到下一列，Esc 取消当前输入。右键菜单的「完整字段编辑…」或 Shift+Enter 打开完整编辑框，支持多行文本和「设为 NULL」。多行粘贴自动展开编辑框。
4. 勾选行后，在已选行的行号或复选框栏右键选择「批量修改已选 N 行…」，或点底栏「批量赋值」，选择字段与统一的新值。只处理明确选中的行，不把 WHERE 条件变成批量 UPDATE。
5. 点击底栏「保存」或 Ctrl/⌘+S，立即提交当前暂存的修改，无二次确认。可在保存前点击「撤销修改」清除本地草稿。
6. 冲突行会标记出来，草稿保留供核对；刷新数据前可选择保留或放弃草稿。保存结果不确定时先检查状态或重新查询核实，不重复写入。

单击单元格选择，Ctrl/⌘+C 复制，只有右键菜单「查看行详情」打开详情；单击行号切换选择；Enter 或 F2 也可开始编辑。多选复选框和底栏按钮在编辑前后保持位置。加载新行后，如当前没有草稿会按需更新编辑快照；有草稿时先保存或撤销，再编辑新加载的行。

返回详情、关闭标签和重新查询都保护未保存修改；切换数据标签保留草稿。连接中断时保留编辑窗口与草稿，但旧快照不能在重连后直接保存。配置修订或插件范围变化会销毁旧会话。草稿不写入磁盘，应用退出不保留。

## 实现边界

- 本次是桌面人工修改通道的安全设计扩展。MCP 工具数量与 MySQL Agent 只读策略不变。
- 新增 mysqlEditOpen / mysqlEditPrepare / mysqlEditCommit / mysqlEditStatus / mysqlEditRelease 五个 preload API，只接受受信任桌面窗口的主框架。
- 桌面预览与查询保留大整数、日期微秒和 JSON 的原始文本，避免首次编辑前就丢失精度；Agent 的读取类型策略不变。
- 数据值采用服务端预处理绑定，兼容 NO_BACKSLASH_ESCAPES，不拼接为 SQL 字面量。
- 每批至多 100 行、2000 个字段值、256 KiB；单值至多 64 KiB。快照有效期 30 分钟，确认计划有效期 2 分钟。每次编辑读取至多 1000 行，同时遵守插件更低的行数和字节限制。
- 要求严格 SQL 模式；数据库权限、唯一性、外键、检查约束仍由 MySQL 执行。数据库原有触发器与级联规则照常生效，应在了解表的业务约束后修改。
- 并发检查比较查询投影中保存的原值；未查询字段的变化不会单独触发冲突。
- 第一版不直接执行新增行、删除行、修改主键、任意写 SQL、跨库编辑或复杂查询结果编辑；生成 SQL 仅输出文本。

## 右键、拖选与 SQL 生成

- 单击单元格聚焦、双击编辑；右键展示编辑、完整字段编辑、复制、行详情等菜单。右键本身和行号点击均不打开详情。只读结果也可从菜单查看详情与复制。
- 在行号或复选框栏按住左键拖动：从未选行开始则连续勾选，从已选行开始则连续取消，重复经过同一行不会反复切换；支持反向拖动、Shift 连选和 Esc 撤销本次拖选。靠近边缘时滚动当前已加载行，拖选期间不触发追加查询。每批最多选择 100 行。
- 右键不改变选择范围；批量修改和 SQL 生成仅在右键目标属于已选行时启用。改变结果筛选条件会清空选择，避免隐藏行被误操作，已有修改草稿保留。
- 结果搜索只筛选已加载数据，保留一个清除按钮；清除后输入焦点留在搜索框。
- 在已选行右键「生成已选行 SQL」选择 SELECT / INSERT / UPDATE / DELETE，预览后复制或保存 .sql。对话框允许切换格式，UPDATE 可选择赋值字段。不会自动执行、自动保存草稿或改变数据库。
- 首版仅支持来源明确的 MySQL 单表 InnoDB 结果和完整主键，复用桌面编辑快照资格检查。复杂查询、跨库、无主键和丢失完整主键的投影拒绝生成。已选行有草稿或显示值无法与快照核对时，要求先保存、撤销或刷新。
- SELECT 用完整主键条件查询当前字段；UPDATE / DELETE 每行使用完整复合主键定位，UPDATE 排除主键及生成列。INSERT 包含查询中的非生成字段及原主键，缺少无默认值的必填字段时拒绝生成。DEFAULT_GENERATED 默认值表达式与真正的计算生成列分别处理。
- 数字保持原始字符串精度；空串、NULL、日期、Unicode 和引号分别编码，反斜杠及控制字符使用 UTF-8 十六进制表达式。无法可靠序列化的二进制等字段拒绝导出对应格式。最多 100 行、4 MiB SQL 文本。
- 新增仅限可信桌面主框架的 mysqlExportSave({fileName,sql}) API。渲染进程不能指定文件路径；用户在系统保存对话框选择路径后才写文件，取消不写入，窗口关闭或导航后失效。导出是用户主动保存业务数据，不在日志、操作记录或查询历史中保存 SQL 内容，MCP 无此文件写入 API。
