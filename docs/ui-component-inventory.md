# UI 组件与图标覆盖清单

本清单是 [整体优化方案](ui-optimization-plan.md) 的源码覆盖附录，基于 2026-10-01 优化前的活动 Renderer。所有评估均以开发、运维桌面工作流为范围。共扫描 142 个 TSX 文件，93 个文件有静态可识别的图标或控件，直接渲染 80 种 Phosphor 图标。组件导入、动态 `Icon`、组件内部生成的图标和运行时禁用条件仍需结合对应功能附录检查；数量是源码出现次数，不是屏幕同时显示的数量。

## 清单如何用于评审

- 图标名称、按钮数量不是改动理由。只有语义不清、无可访问名称、交互状态不一致或影响工作效率时才修改。
- 同一动作的图标、提示、快捷键和确认路径按主方案的动作词汇检查；组件已有合理功能则保留。
- 各文件的保留、修改和待验证判定见“评估依据”列。共享组件的状态规范统一作用于调用方，不在每个页面重复实现。
- 本附录记录评估时的覆盖范围；交付后的行为与验证结果以主方案实施记录为准。
