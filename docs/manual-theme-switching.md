# 手动主题切换

入口在最左侧项目栏底部、“新增项目”按钮上方。按钮显示当前选择及相应图标，收起为 128px 项目栏时仍可使用；主题行独立于项目和环境的新增按钮，不改变原有底部对齐。

提供三种选择：

- 浅色：始终使用浅色，不受系统主题变化影响。
- 深色：始终使用深色，不受系统主题变化影响。
- 跟随系统：默认选项，系统改变时实时更新；从手动模式切回来也会立即应用当前系统主题。

选择立即作用于页面、菜单和通知提示，使用现有明暗色彩变量，不修改业务状态、插件连接或凭据。菜单使用原有 Radix 单选菜单，支持方向键、Enter 和 Escape，选中或关闭后回到触发按钮。

偏好以 `light`、`dark` 或 `system` 三种值保存到本机 `localStorage`，键为 `runbook-bridge:theme-preference:v1`。刷新和重启后恢复。无值或非法值回退“跟随系统”；浏览器存储不可用时不会阻止启动或当前窗口切换，但此时无法保证重启保留。没有新增 IPC、网络访问或生产依赖。

Renderer 在 `createRoot` 前读取偏好并设置根节点主题，Provider 复用同一解析逻辑，通知组件使用相同的实际主题。原生 Windows 窗口标题栏及加载占位仍由已有 Electron/系统行为管理，本次不声称它们也会随手动选择同步。
