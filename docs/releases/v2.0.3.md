# 2.0.3 · Redis 长 JSON 完整浏览

本版于 2026-10-10 通过现有 HTTPS 云配置仓库分发 Windows x64 安装包，版本高于 2.0.2，使已安装用户能够检测到更新。GitHub 公开稳定版和下载入口保持 2.0.0，本次不创建 GitHub Release。

## 更新内容

- 修复 Redis 长 JSON 只能显示前 64 KiB 的问题。点击「加载更多内容」按段追加，全部加载后可以完整格式化、搜索和复制，无需调整插件配置。
- 分段读取保留中文及 emoji 字符边界，不改变大整数或原始文本；读取失败保留已加载部分，内容大小变化时要求刷新。
- 单次读取预算、Key 范围、游标作用域、浏览缓存预算及原有编辑上限保持不变。超出编辑上限的值可以完整浏览，仍保持只读。
- 包含 2026-10-09 本地构建的插件配置编辑优化：修改地址后默认沿用已保存密码，检查成功且配置未变时直接保存，并保留具体认证错误。桌面处理新地址首次 SSH 指纹的行为沿用该构建，已知指纹变化仍拒绝。

## 用户更新

已安装 2.0.2 的用户，在“设置 → 关于 → 软件更新”选择已绑定且解锁的 HTTPS 云仓库，检查并下载 2.0.3，保存工作后点击“重启并更新”。安装沿用原目录和 `AIOpsTool` 数据，不自动删除项目、凭据或仓库关联。

旧 2.0.0 / 2.0.1 更新器可能仍等待隐藏安装向导，处理方式见 [2.0.2 修复说明](v2.0.2.md)。原 GitHub 2.0.0 没有在线更新入口，需手动运行新版安装包。

## 发布文件

Windows x64 发布目录为 `updates/win32/x64/`，包含 `latest.yml`、`RunbookBridge-2.0.3-win32-x64.exe` 及可选的同名 `.blockmap`。先上传并校验安装包，最后原子替换版本清单，已发布旧版本文件保持不变。
