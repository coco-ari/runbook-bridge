# 2.0.0 · Windows 稳定版

本版将 2.0 工作区正式发布为 Windows x64 稳定版，并设为 GitHub Latest。包含此前公开测试版以来的人工工作区、Agent 接入、日志读取和界面改进。macOS 继续提供源码构建支持，本次不发布 Mac 安装包。

## 主要能力

- 按项目和环境管理 Server、MySQL、Redis；通过 MCP 让现有 Agent 结合日志、服务、数据库与缓存进行排查。
- 人工服务器工作区提供 SSH 多终端、文件浏览与编辑、上传下载、传输进度和 Docker 只读浏览。
- MySQL 支持表格草稿编辑、受限 SQL 批量执行与事务管理，区分已提交、已回滚和待核实结果。
- Redis 提供键搜索、分层浏览、String/JSON 编辑、过期设置和单 Key 删除。
- 云配置支持按项目上传更新、版本历史与恢复；本地配置页提供 Codex 一键接入、主题和版本信息。
- 汇总测试版以来的日志断点续读、传输反馈、Agent 接入识别和侧栏配置按钮改进。
- 修复项目拖拽期间提示框的尺寸观察循环和高缩放下文件工具栏按钮越界。

## 下载与升级

下载 `RunbookBridge-Setup-2.0.0.exe`，并用同名 `.sha256` 文件核对 SHA-256。Source code 压缩包是源码，不是安装包。当前 Windows 安装包尚未进行发布者数字签名，系统可能提示未知发布者。

升级前完全退出应用，并备份 `%LOCALAPPDATA%\AIOpsTool`；自定义数据目录用户备份对应目录。2.0 稳定版、此前测试版和 1.x 版本共用安装位置及数据，不要同时运行。跨大版本降级兼容性尚未保证。

## 使用边界

- 连接仍由用户主动发起；Agent/MCP 的 MySQL、Redis 接口保持只读，文件变更、服务控制与 Shell 操作继续按原有流程确认。
- 人工 SQL 受固定数据库、语句策略及事务条件限制，不支持 DDL、跨库和任意 SQL；详见 SQL 执行说明。
- 草稿和 SQL 会话仅在当前会话内保留；写入结果待核实时请先核实，避免重复提交。
- 日志、文件及查询结果可能包含业务信息，并由所用 AI 客户端处理。
- MySQL 表名搜索目前覆盖已加载数据表；大规模 Redis 列表和审计历史的性能优化将继续迭代。
