# 2.0.8 云仓库发布说明

## 修复内容

- 修复插件编辑会话结束或过期后，保存失败且取消无法退出的问题。
- 配置编辑底部只提供「保存」与「取消」；取消直接丢弃本次输入，不再二次询问，也不保留可恢复草稿。
- 取消不修改原有配置和已保存凭据；再次打开编辑读取已保存配置。保存前检查失败不提交，保存提交中暂时禁止取消。
- 已保存但连接恢复失败时单独说明结果；保持窗口归属、配置版本和凭据安全校验。

## 发布范围

计划通过现有 HTTPS 云仓库发布 Windows x64、Mac arm64 与 Mac x64 的 2.0.8 安装包。保留旧版本文件，不创建 GitHub Release。

Windows 沿用 NSIS 下载、确认和安装流程。Mac 使用临时签名、未经 Apple 公证的 DMG 与 ZIP，下载后按提示手动覆盖安装，不改变系统安全设置。

## 验证与发布状态

- 修复提交的完整单元测试通过（2076 项通过、5 项按平台跳过），语法和类型检查、保存失败与直接取消专项、基础界面验证通过。
- 本版本的三端构建、包验证和覆盖升级验证由现有云仓库构建工作流执行；最终发布以各平台清单为准。
- 发布时先校验并上传安装包，最后原子替换更新清单，不能覆盖已发布旧版本的安装包。
