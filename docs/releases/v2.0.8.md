# 2.0.8 云仓库发布说明

## 修复内容

- 修复插件编辑会话结束或过期后，保存失败且取消无法退出的问题。
- 配置编辑底部只提供「保存」与「取消」；取消直接丢弃本次输入，不再二次询问，也不保留可恢复草稿。
- 取消不修改原有配置和已保存凭据；再次打开编辑读取已保存配置。保存前检查失败不提交，保存提交中暂时禁止取消。
- 已保存但连接恢复失败时单独说明结果；保持窗口归属、配置版本和凭据安全校验。

## 发布范围

Windows x64、Mac arm64 与 Mac x64 的 2.0.8 安装包已通过现有 HTTPS 云仓库发布，三个更新清单均已启用。保留旧版本文件，不创建 GitHub Release。

Windows 沿用 NSIS 下载、确认和安装流程。Mac 使用临时签名、未经 Apple 公证的 DMG 与 ZIP，下载后按提示手动覆盖安装，不改变系统安全设置。

## 验证与发布状态

- 修复提交的完整单元测试通过（2076 项通过、5 项按平台跳过），语法和类型检查、保存失败与直接取消专项、基础界面验证通过。
- 三端构建、包验证和安装覆盖验证通过；Mac 从 2.0.7 到 2.0.8 的原生覆盖升级复验通过，原始失败记录和后续复验记录见下文。
- 发布前备份旧清单，安装包完整落盘后原子替换对应清单。原 Windows 2.0.6 与 Mac 2.0.7 文件保留并再次通过摘要校验。

Windows 安装包来自干净提交 `57e90ef6ff444d73e527d0b352cf27ac1c0f2f94`，[构建与安装覆盖验证通过](https://github.com/coco-ari/runbook-bridge/actions/runs/38520355591)。发布前已验证服务器接口及公网 HTTPS 的完整 EXE、blockmap 下载与 SHA-512；备份旧清单后原子启用 2.0.8，内外网清单摘要均与发布计划一致。

Mac 两种架构来自同一干净提交。[原生构建](https://github.com/coco-ari/runbook-bridge/actions/runs/38520361776)的检查、单元测试、界面测试、包结构、MCP、包内界面与签名验证通过，首轮覆盖回归停在钥匙串授权。排查后修正测试预置账户名缺少 `Key` 后缀的问题，并移除覆盖后不必要的授权改写；未更改应用的钥匙串策略或安装包内容。

使用原始归档包的[双架构覆盖升级复验已通过](https://github.com/coco-ari/runbook-bridge/actions/runs/38524648763)：在各自原生 Runner 上从 2.0.7 覆盖到 2.0.8，确认三个合成插件凭据可读、原插件配置及主备凭据文件保留、MCP 可列项目和打开环境、移除测试应用后隔离数据保留。测试只预授权两个精确构建，不替代用户设备上的 Gatekeeper、Finder 交互和钥匙串允许或拒绝操作验收。

三个正式更新清单均通过内网接口及公网 HTTPS 读取与摘要校验，指向 2.0.8。两个 Mac DMG 均通过公网分段完整下载与最终 SHA-512 校验，证书验证保持启用。两个兼容 ZIP 完成本地及服务器下载接口的完整摘要校验；其公网完整复验因慢链路和连接中断未完成，不计入公网完整下载通过项。
