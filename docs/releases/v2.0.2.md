# 2.0.2 · Windows 在线安装修复

本版通过现有 HTTPS 云配置仓库分发 Windows x64 安装包，修复点击“重启并更新”后客户端关闭、安装没有完成且软件没有重新打开的问题。本次不创建 GitHub Release，GitHub 公开稳定版和下载入口继续保留 2.0.0。

## 修复内容

### 2026-10-09 本地重新打包

本次保留 2.0.2 版本号，补充插件配置编辑优化：修改 IP、端口或账号后默认沿用当前插件已保存的密码，输入新值才替换；桌面检查或保存时自动接受新地址的首次 SSH 指纹，修复重复弹窗，已有地址的已知指纹变化仍报错。已通过检查且配置未变时不重复验证，认证失败时保留具体错误。本地重新打包不表示已发布到云仓库或 GitHub，也不会向已安装的同版本客户端触发版本升级提示。

### 在线安装修复

旧更新器启动非静默 NSIS 安装，但安装进程的窗口被隐藏，向导仍在等待用户输入。因此客户端已经退出，安装程序却无法继续，也不会重新打开客户端。

2.0.2 将在线安装改为静默模式，并要求安装成功后重新打开客户端。正常成功流程只需客户端退出和重新打开一次，无需重启电脑。首次手动安装仍保留安装向导；Windows 权限或安全提示仍可能出现，不能保证所有系统都无需交互。

检查与下载继续在后台进行，下载期间可以使用工作台。下载完成不会自动安装；用户点击“重启并更新”并确认后，客户端仍会复核安装包、检查活动任务与未保存内容，再关闭连接并开始安装。原有数据目录、云仓库关联、SHA-512 校验及操作权限边界保持不变。

## 从旧更新器完成修复安装

安装参数由发起升级的客户端决定。含更新功能的旧 2.0.0 和 2.0.1 即使下载的是 2.0.2，仍可能遇到隐藏向导问题；只有安装本版后，后续在线升级才会使用新的静默流程。

1. 如已有安装程序等待输入，先完成或退出该安装程序，避免同时启动多个安装程序。
2. 从可信云仓库取得 2.0.2 安装包，手动运行并按向导完成安装，沿用当前安装目录。
3. 打开客户端，在“设置 → 关于”确认版本为 **2.0.2**，检查项目与云仓库关联仍在。
4. 后续有更高版本时，在软件更新区域检查并下载，保存工作后点击“重启并更新”，体验静默安装与自动重新打开。

原 GitHub 2.0.0 安装包没有在线更新入口，首次使用同样需要手动安装支持更新的客户端。升级沿用 `AIOpsTool` 数据目录，不通过卸载删除数据；备份方法见[升级与已知限制](../beta-guide.md)。

Windows x64 发布目录为 `updates/win32/x64/`，包含 `latest.yml`、`RunbookBridge-2.0.2-win32-x64.exe` 及可选的同名 `.blockmap`。先上传并校验安装包，再原子替换版本清单；已发布的 2.0.1 文件保持不变。
