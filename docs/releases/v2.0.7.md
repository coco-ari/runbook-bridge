# 2.0.7 · 工作区直接关闭

## 使用变化

- 服务器、MySQL、Redis 工作区的关闭按钮与工作区列表中的关闭入口均直接关闭，不再要求二次确认。
- 关闭会丢弃当前工作区的未保存草稿、查询与浏览状态，结束人工终端，并释放 SQL 会话、回滚未提交事务；插件连接保持，其他工作区不受影响。
- 保存或文件传输仍在进行时，先等待任务结束。Redis 写入结果尚未确定时，先核实结果再关闭；MySQL 会话释放失败时保留工作区并显示错误。
- 「返回详情」继续保留工作区。单个文件、SQL / Key 标签、数据写入和应用退出的确认规则保持原有行为。

## 分发

本次通过现有 HTTPS 云仓库发布 Mac arm64 和 Mac x64 的 DMG、ZIP 与独立更新清单，Windows x64 保留 2.0.6。保留旧版本文件，不创建 GitHub Release。

已安装 2.0.6 的 Mac 用户在「设置 → 关于 → 软件更新」选择已连接的海外仓库，检查更新并下载 2.0.7。校验完成后打开 DMG，退出旧应用，再拖入 Applications 覆盖安装。

沿用手动安装通道的临时签名，未进行 Apple 公证，不自动替换正在运行的应用。
