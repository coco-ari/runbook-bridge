# 2.0.4 · 运维说明 Markdown 与工作台交互改进

本版通过现有 HTTPS 云配置仓库分发 Windows x64 安装包。版本高于 2.0.3，已安装用户可检查到更新；GitHub 公开稳定版和下载入口保持 2.0.0。

## 更新内容

- 运维说明阅读与预览支持 Markdown 标题、加粗、列表、引用、代码块、表格和任务列表。宽表格与长代码可横向滚动，编辑保存仍保留原文和 64 KiB 限制。
- HTML 按文本显示，图片不自动加载，链接展示文字和地址；预览、保存、放弃草稿及版本冲突处理保持一致。
- 统一工作区、消息中心、设置入口和弹层的字体及颜色，改善深浅主题一致性。
- 修复安装路径含 `~` 时页面地址编码不一致，导致凭据查看等桌面操作被误拒绝的问题；页面加载与访问校验共用精确地址。
- 包含 2.0.3 之后的环境分组、紧凑插件列表、窄窗导航、配置身份核对、草稿保护及保存恢复反馈改进。
- 包含云仓库与软件更新提醒、全局待确认入口及 Redis 长 JSON 查看改进。云端推送需要对应服务版本，旧服务继续使用定时检测。

## 用户更新

在“设置 → 关于 → 软件更新”选择已绑定且解锁的 HTTPS 云仓库，检查并下载 2.0.4，保存工作后点击“重启并更新”。升级沿用现有安装目录和 `AIOpsTool` 数据，保留项目、凭据与仓库关联。

旧 2.0.0 / 2.0.1 更新器的隐藏向导问题见 [2.0.2 修复说明](v2.0.2.md)。macOS 保留源码构建，尚未开放在线安装。

## 发布文件

Windows x64 发布目录为 `updates/win32/x64/`，包含 `latest.yml`、`RunbookBridge-2.0.4-win32-x64.exe` 及可选的同名 `.blockmap`。先完整上传并校验安装包，最后原子替换最新清单，保留旧版本文件。
