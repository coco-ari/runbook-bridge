# RunbookBridge 0.3.0

0.3.0 的重点是提升 Codex 执行旧项目部署和生产日志排查时的效率，同时保持“凭据不进入对话、用户控制 SSH 连接、Linux 低权限账号作为安全边界”的产品方向。

## 主要变化

- 新增 `execute_batch`：最多顺序执行 10 条独立命令，减少多步检查、备份和启动流程的 MCP 往返。
- 新增 `search_logs`：通过 SFTP 读取受限日志快照，在本机进行关键词 AND/OR 搜索，返回前后文、分页和截断信息。
- `contextToken` 支持安全复用，并绑定项目文档、SSH 会话代次和安全配置。
- 增加 VPN 切换和网络抖动后的自动重连；SSH 认证失败会停止重试，避免账号锁定。
- 审计增加 `operationId`、结果、输出大小和截断信息。
- 删除实验性的会话权限模式，保留默认危险命令拦截，最终权限继续由低权限 Linux 账号决定。

## 升级方式

1. 退出 AI 运维工具。
2. 安装 0.3.0，可覆盖原安装目录。
3. 完全退出并重新启动 Codex。
4. 启动 AI 运维工具并连接项目。
5. 在 Codex 中调用 `list_projects`，确认 MCP 与桌面端版本均为 `0.3.0`。

通常不需要重新执行 `codex mcp add`。现有项目配置、Markdown、加密凭据和下载目录会继续使用。

## 自动重连行为

- 网络断开、连接超时等临时错误：继续退避重试。
- SSH 密码、私钥或私钥口令认证失败：停止自动重连，等待用户重新连接。
- 主机指纹变化、私钥文件不可用、凭据无法解密和无效代理配置：停止自动重连，等待用户检查配置。
- 用户点击“断开”、删除项目或退出程序：取消自动重连。

## 已知限制

- `execute_batch` 不是事务，也不会自动回滚已经成功的步骤。
- `search_logs` 只支持字面量搜索，不支持正则、时间范围和自动业务时间线。
- 日志搜索权限等同于项目 SSH 账号的文件读取权限，Markdown 仅用于指导 Agent。
- 危险命令策略不是 Shell 沙箱。请使用无任意 `sudo` 的专用低权限 Linux 账号。
