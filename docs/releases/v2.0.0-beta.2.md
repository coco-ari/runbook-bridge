# 2.0.0-beta.2 · 数据库编辑与排障工作区

这是面向开发者的 Windows 公开测试版，不替换稳定版 1.0.46 的 Latest 入口。建议先在测试环境使用。

## 本版重点

- MySQL 支持有完整主键的 InnoDB 单表新增、复制、修改和删除，草稿以文字及颜色标记，统一保存或取消。
- 数据表格采用紧凑布局、图标工具栏和可拖动列宽；操作反馈使用固定区域，减少页面跳动。
- Redis 支持 String/JSON 新增编辑、TTL 设置和五种常用类型的单 Key 删除。
- 弱网操作原位转圈，长时间等待显示耗时；区分写入成功与刷新失败，结果不确定时保留核实入口并禁止重复提交。
- 汇总自 beta.1 以来的服务器文件导航、传输与终端恢复改进，以及 Docker 只读浏览、云配置等功能；详见工作区指南。

## 下载与安装

下载 `RunbookBridge-Setup-2.0.0-beta.2.exe`，并用同名 `.sha256` 文件核对 SHA-256。Source code 是源码压缩包，不是安装包。附带的界面 PNG 来自合成测试数据。

当前 Windows 包未进行发布者数字签名，系统可能提示未知发布者。请核对来源和校验值，并遵守所在组织的安装要求。本版不提供 Mac 正式包；Mac 签名和公证尚未完成。

## 升级前请阅读

退出应用并备份 `%LOCALAPPDATA%\AIOpsTool`；自定义数据目录用户应备份对应路径。稳定版与测试版共用安装位置和数据，不要同时运行。跨大版本降级兼容性尚未保证。

MySQL/Redis 的 Agent 接口继续只读；桌面人工写入不扩大 Agent 权限。草稿只在当前会话内保存。提交结果不确定时先核实，不要重复保存。日志和查询结果可能含业务信息，请确认所用 AI 客户端的数据处理方式。
