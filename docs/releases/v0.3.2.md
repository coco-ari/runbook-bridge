# RunbookBridge 0.3.2

发布日期：2026-08-14

## 本次修复

0.3.2 修复了 SFTP 文件请求与 SSH 通道关闭之间的竞态。在旧版本中，日志搜索、上传或下载刚结束，或网络在传输中断开时，底层仍可能存在尚未回执的 SFTP 请求。此时关闭通道会产生 `No response from server`，极端情况下该错误没有被 Electron 主进程接住，从而弹出 JavaScript 错误窗口。

新版本统一管理 SFTP 的超时、中止、运行期错误和关闭流程，并让日志读取显式等待远端文件句柄关闭。连接中断现在会作为 `TRANSFER_INTERRUPTED` 返回给 Codex，不再成为主进程未捕获异常。

## 用户影响

- 项目、Markdown 文档、加密凭据和服务器指纹无需迁移。
- MCP 工具名称和调用参数不变。
- 网络中断时，正在执行的上传或部署结果仍可能不确定；Codex 应重新读取项目并确认服务器状态后再决定是否重试。
- 上传在硬断线前产生的远端随机 `.part-*` 文件可能暂时保留，不会被当作最终文件使用；可在项目运维文档中约定定期清理旧临时文件。

## 升级

安装 0.3.2 后完全退出并重新启动 Codex。原 MCP 注册路径不变，通常不需要重新安装或重新注册 MCP。
