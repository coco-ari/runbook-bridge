# 2.0.6 · Mac 辅助更新与平台独立发布

本版通过现有 HTTPS 云配置仓库分发。Windows x64、Mac Apple Silicon（arm64）与 Intel（x64）各有独立安装包和版本清单，分别验证后上线；实际发布状态以云清单为准。GitHub 公开稳定版和下载入口保持 2.0.0。

## 更新内容

- Mac 安装版自动检查当前平台和程序架构的版本，用户点击后下载 DMG，校验大小与 SHA-512，完成后可打开安装包或在 Finder 中定位。
- 打开前再次校验下载内容和来源，失败时不执行安装包。下载保留隔离属性，继续接受 macOS 系统安全检查。
- 提示保存工作、退出应用和使用 MCP 的 Agent 客户端，把新版应用拖到原安装位置并选择替换，再从原位置启动。
- Mac 无需 Apple 开发者账号即可使用此辅助更新通道；未公证安装包仍可能出现系统安全提示，不自动替换、自动重启或恢复跨重启下载状态。
- Windows 保留原有下载、确认、退出和安装流程；只更新一个平台的云清单不会触发另一个平台升级。
- 恢复环境展开按钮的 32px 点击区域，补充双架构构建、更新专项和打包回归。

## 用户更新

Windows 已安装含更新功能的旧版用户，在“设置 → 关于 → 软件更新”选择已绑定且解锁的 HTTPS 云仓库，检查并下载 2.0.6，保存工作后确认安装。

Mac 首次使用须手动安装包含此功能的客户端。后续更新按“检查 → 下载并校验 → 打开 DMG → 退出后覆盖安装”完成；Apple Silicon 上运行 x64 程序时继续下载 x64 包。沿用原安装位置和 `~/.ai-ops-tool` 数据目录，不卸载或删除数据。钥匙串兼容性与系统首次启动提示须在实际 Mac 上验收。

- Windows x64 已启用云更新清单，版本为 2.0.6；线上 EXE 和 blockmap 已通过完整下载及 SHA-512 校验，保留 2.0.5 文件。构建提交为 `f8946c8769e94f4ea1e12d26bd0e33a628bd75d8`，[发布专项通过](https://github.com/coco-ari/runbook-bridge/actions/runs/38388337272)。
- Mac arm64 和 x64 的 2.0.6 候选包均已上传云服务，四份 DMG、ZIP 均通过服务器接口完整下载及 SHA-512 校验，构建提交为 `abd5f9c0e497893449223cbe63375b9c584b305b`。两种架构均通过语法、类型、单元、基础界面、软件更新专项、包内界面、MCP 和代码签名检查；候选包及 2.0.5 基准包保存在[原生构建归档](https://github.com/coco-ari/runbook-bridge/actions/runs/38395491978)。
- Mac 两个 `latest-mac.yml` 均未启用。跨版本回归成功完成旧版凭据写入、读取和覆盖，但新版读取凭据时仍出现系统钥匙串授权窗口，自动回归超时；尚不能宣布旧版凭据在升级后已验收通过。需要在实际 Mac 上允许钥匙串访问，确认原项目及三类插件凭据可读、MCP 可重新接入，再启用清单。候选文件与正式更新状态须分开判断。

- 未公证 Mac 包的 Gatekeeper 首次启动和用户手动允许、拒绝钥匙串访问仍需人工验收。
