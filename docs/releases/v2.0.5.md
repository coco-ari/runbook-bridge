# 2.0.5 · 数据库一键保存与云仓库提醒改进

本版通过现有 HTTPS 云配置仓库分发 Windows x64 安装包。版本高于 2.0.4，已安装用户可检查到更新；GitHub 公开稳定版和下载入口保持 2.0.0。

## 更新内容

- 修改数据库表格后点击保存即可提交。桌面自动为独立写入连接准备并验证严格模式，无需用户修改数据库全局配置。
- 保存时显示进度，成功后显示已保存；响应丢失时自动查询同一次操作的结果，避免重复写入。失败保留草稿，字段错误可定位并修正后重试。
- 保留事务回滚、数据校验、删除确认和审计。Agent 的 MySQL 访问继续只读，自动初始化仅作用于桌面写入会话。
- 首次关联云仓库时，已有项目正常显示但不再产生历史新增提醒；后续新增和修改继续提醒。
- 包含工作区窄屏数量角标、页头溢出及特殊安装路径访问校验修复，以及此前版本的 Markdown 与工作台交互改进。

## 用户更新

在“设置 → 关于 → 软件更新”选择已绑定且解锁的 HTTPS 云仓库，检查并下载 2.0.5，保存工作后确认安装并重启。支持从含更新功能的旧版直接升级，无需逐版安装；升级沿用现有安装目录和 `AIOpsTool` 数据，保留项目、凭据与仓库关联。

旧 2.0.0 / 2.0.1 更新器的隐藏向导问题见 [2.0.2 修复说明](v2.0.2.md)。macOS 保留源码构建，尚未开放在线安装。

## 发布文件

Windows x64 发布目录为 `updates/win32/x64/`，包含 `latest.yml`、`RunbookBridge-2.0.5-win32-x64.exe` 及可选的同名 `.blockmap`。先完整上传并校验安装包，最后原子替换最新清单，保留旧版本文件。
