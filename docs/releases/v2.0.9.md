# 2.0.9 云仓库发布说明

## 更新内容

- MySQL 地址、账号、凭据和隧道只维护一份。读取数据库后可批量选择；已有单库可增加关联数据库，界面按数据库组展示。
- 支持整组连接、断开、删除，以及单插件右键删除。删除只移除工作台配置，不删除服务器上的数据库。
- 每个数据库仍有独立插件标识和权限；MCP 继续固定单库只读，不允许跨库查询，表结构按需加载。
- 修复编辑期间读取数据库被门禁拦截，以及保存的 MySQL 凭据不可读时无法确认替换的问题。共享配置、凭据和成员变更在同一事务内提交，失败恢复原状态。

## 升级与云仓库

首次启动自动迁移旧单库配置，保留原插件标识、固定数据库和权限，并保存加密恢复记录。普通单库保持独立；旧批量组仅在连接和凭据一致时合并。迁移失败保留原配置并隔离对应项目，避免覆盖。

云快照使用格式 5，新版可以读取历史格式。团队须统一升级至 2.0.9 后再上传新格式配置；旧客户端不能读取新版快照。云仓库服务端继续保存加密内容，无需更新服务端代码或迁移云端数据库。详见 [MySQL 共享连接与迁移](../mysql-plugin-groups.md)。

## 发布范围与验证

准备发布 Windows x64、Mac arm64 与 Mac x64，保留已有版本文件，不创建 GitHub Release。Windows 沿用 NSIS 安装流程；Mac 使用临时签名、未经 Apple 公证的 DMG 与 ZIP，下载后手动覆盖安装。

语法和类型检查通过，完整单元测试 2124 项通过、5 项按平台跳过。基础界面、MySQL 数据库组专项及 Windows 包内 125 项桌面接口、42 个 MCP 工具和 178 次插件生命周期调用通过，凭据明文泄漏检测为零。

正式安装包来自干净提交 `65055d32399b08ef5eb7c068b599c3a6f3b24168`。[Windows 构建与安装覆盖验证通过](https://github.com/coco-ari/runbook-bridge/actions/runs/39018583723)。同一源码的本地 Windows 安装包另行通过从已发布 2.0.8 的真实覆盖升级：旧单库转为共享连接引用，三个合成凭据可读，无关插件逐字节保留，MCP 正常，卸载测试应用后数据仍保留。

[Mac 双架构原始构建](https://github.com/coco-ari/runbook-bridge/actions/runs/39018608017)的检查、单元测试、界面、打包应用、MCP 和签名验证通过。首轮升级回归停在测试预期：旧版未写入 `tags` 时，新版规范化补齐空数组；数据库、权限和凭据均未因此改变。已在 `419306a` 修正断言，使用同一批原始候选包的[双架构覆盖升级复验通过](https://github.com/coco-ari/runbook-bridge/actions/runs/39019777531)：从 2.0.8 升级至 2.0.9，共享连接迁移、三个凭据读取、MCP 操作和卸载后数据保留均通过。测试只为精确构建预授权隔离钥匙串，不替代用户设备上的系统授权交互。
