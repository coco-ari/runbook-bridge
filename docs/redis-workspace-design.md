# Redis 工作区

Redis 插件连接完成后，在插件详情的连接操作旁点击「打开 Redis 工作区」。首版提供固定 Logical DB、已登记 Key 范围内的只读浏览，不提供写入、删除、修改 TTL、切库、命令控制台或实例监控。

## 浏览与查看

- 树上方只保留两行：第一行展示固定 DB、当前 Key 范围与刷新、视图切换、更多工具；第二行提供搜索框。只有多个已登记范围时才显示范围切换菜单，单个范围直接展示。配置为 `*` 时显示「全部 Key（*）」，没有范围时不会自动扩大授权。
- 搜索默认按关键词字面包含匹配；勾选「精确匹配」后直接定位完整 Key，仍检查当前范围。Enter 或搜索按钮提交，输入过程和切换匹配方式不触发请求。
- Key 默认按冒号 `:` 分层显示为目录树，支持目录展开/折叠和完整名称列表切换。「更多工具」菜单提供定位当前 Key、全部展开/折叠和收起 Key 列表。叶子显示剩余名称，悬停和底部路径栏显示完整 Key；同名 Key 和目录分别保留。目录数字只统计已加载的 Key。
- 搜索结果保留层级并展开匹配路径，继续扫描会合并到原目录并保留展开状态；「定位当前 Key」可展开路径并滚动到已加载的当前 Key。方向键、Home、End 导航目录，Enter 打开 Key，Ctrl / Command + Enter 固定标签。异常深层 Key 的前 12 层显示目录，其余部分保留为完整叶子名称。
- SCAN 按批次继续，只显示已加载数量。空批次不表示完成；返回游标结束才表示本轮完成。外部数据可能变化，不保证静态快照。列表不逐项查询类型或 TTL。
- 单击 Key 使用临时预览标签，双击固定，最多 8 个标签。每个标签独立保留显示方式和滚动位置。
- String 支持文本、完整合法 JSON 格式化及十六进制；Hash 显示字段和值并支持精确字段读取；List 显示索引和值；Set 显示成员；ZSet 显示从零开始的排名、成员和分数。其他类型只显示类型、TTL 等可用摘要。
- TTL 是读取时的采样值，区分剩余时间、不过期和不存在，不自动轮询。刷新 Key 会重新读取元数据和内容。
- 内容区顶部将类型标签、Key 名称与「复制 Key」图标集中排列；大小或成员数、TTL、读取时间位于下一行，刷新图标紧邻采样时间。文本、JSON、十六进制使用分段切换，旁边的「复制内容」复制当前显示内容；截断时明确显示「复制已加载部分」。数据以纯文本渲染，JSON 不执行代码或 HTML。
- 左侧栏可拖动调整或折叠，Ctrl / Command + F 聚焦 Key 搜索；标签支持方向键、Home、End 和 Delete。

## 会话与限制

「返回详情」隐藏工作区并保留数据，隐藏期间不发起后续读取；点击「返回 Redis 工作区」继续浏览。「关闭工作区」确认后清除数据和读取通道，插件主连接保持。切换插件、断连、配置修订、删除所属资源和窗口销毁都会失效旧会话，迟到请求不能恢复它。

Key 每批最多 100 条，集合每批最多 50 条，均受插件 `maxKeys` 限制；列表最多保留 5,000 个 Key。内容预览沿用 `maxValueBytes`（默认 64 KiB），超大 Hash 单字段不读取正文。UTF-8 截断保留字符边界；二进制 Value 可查看十六进制，首版不增加二进制 Key 操作。

Redis 的 COUNT 是提示而非严格条数保证，扫描超额余项在主进程暂存后续展示，不截掉结果后推进游标。游标有效期五分钟，绑定窗口、作用域、配置修订、连接对象、查询和数据类型；不允许跨查询续页。前端对重复 Key、字段、成员去重。缓存预算合计 16 MiB，其中主进程余项占 4 MiB，Renderer 浏览数据占 12 MiB；这不是进程总内存限制，协议解析与界面渲染仍有临时内存开销。

每插件最多一个桌面读取请求，整次请求共用插件超时。独立 RESP2 通道使用已验证主路由端点和相同认证、DB、TLS 参数，不创建或替换主路由。解析阶段检查声明长度和累计回复，单次回复最大 1 MiB，并限制数组节点和嵌套深度。超限、超时或格式错误关闭该读取通道，不关闭插件主连接；不会将失败伪装为没有数据。

## 桌面接口与安全边界

新增 `redisWorkspaceScan`、`redisWorkspaceInspect`、`redisWorkspaceRead`、`redisWorkspaceRelease` 四个 preload API，沿用 `IpcResult`。数据请求携带项目、环境、插件及 `patternId`，不接受凭据、地址、任意命令或切库参数。

IPC 校验可信主窗口及主 frame；服务层检查完整作用域、当前连接、配置状态和内置操作授权，操作前后均复核会话。窗口及工作区释放凭证还覆盖等待审计时的竞态，旧请求不能在释放后重新建立读取通道。读取共用既有用户操作审计；开始审计失败时不访问 Redis，完成审计失败返回 `auditWarning`。审计不保存 Key、Value、字段、搜索词或服务端错误正文。

这些是桌面人工只读能力，不增加 MCP 工具，不扩大 Agent 的 Redis 读取能力，不修改工作区 YAML 格式或凭据模型。内容仅驻留内存，复制只在用户明确点击时发生。

## 验证

```powershell
node --test test/redis-workspace.test.mjs test/redis-plugin-runtime.test.mjs
corepack pnpm run check
corepack pnpm test
corepack pnpm run test:ui
corepack pnpm run test:ui:redis
```

Redis 专项测试使用本机回环 RESP2 fixture，验证分页余项、游标隔离、字节限制、超时、关闭竞态、审计和主连接隔离。Electron 专项使用隔离数据根与 mock IPC，验证入口、五种类型、复制、主题、分栏及会话清理。正式包 UI smoke 另以回环 Redis fixture 验证真实 preload、IPC、认证、读取和工作区入口，不连接生产基础设施。
