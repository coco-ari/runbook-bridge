# 2026 年 10 月 UI 复审与改进

评估日期：2026-10-11。实现基线：`0be5988`，分支 `feat/ui-experience-review`。本轮在独立 worktree 实施，主工作区已有的未提交改动不包含在本分支。

## 结论

现有设计适合开发与运维工作：项目 → 环境 → 插件的范围清楚，专业工作区独立，绿色强调色、深浅主题和公共控件已有统一规范。当前最值得改进的是查找资源、辨认连接状态、窄窗口空间分配和配置表单的阅读顺序。继续增加卡片、颜色或装饰不会解决这些问题。

本轮保留产品结构，完成下表中的重点改进。没有修改远程操作、授权、凭据、环境隔离或确认绑定规则。

## 已实施的优先项

| 优先级 | 问题与影响 | 实施结果 | 验证重点 |
| --- | --- | --- | --- |
| P1 | 960px 窗口中默认两栏导航占 544px，详情只有约 414px，表单和记录频繁换行 | 960–1119px 窗口按需临时收窄导航；960px 默认项目栏 176px、资源栏 240px，详情 542px，比原先增加 128px，约 31% | 放大恢复首选宽度，窗口变化不覆盖已保存布局；详情折叠时保留首选导航宽度 |
| P1 | 能搜“订单”，却不能按“生产 订单”定位资源；跨环境同名资源查找成本高 | 项目、环境、插件类型加入检索上下文，多个词独立匹配且不依赖输入顺序 | 正序、逆序、类型组合、大小写和空白；错误环境不返回目标 |
| P1 | 资源名称与辅助信息都是 12px，正常行重复“配置完整”，异常主要依赖小图标 | 名称恢复规范中的 13px；辅助行显示已连接、连接失败、连接受阻等实际状态；未完成配置仍显示配置提示 | 深浅主题和真实状态；继续保留状态图标及可访问名称 |
| P2 | 资源栏变窄后，连接按钮与环境类型抢占名称空间 | 资源栏低于 280px 时连接动作显示为 28px 图标按钮，保留完整动作提示和可访问名称；环境类型移到辅助行 | 名称、状态、操作不重叠，环境身份仍有文字；维持环境约 48px、插件约 40px 的行高 |
| P2 | 操作记录的低频筛选在窄详情中占用多行，挤压实际记录 | 搜索和时间常驻；窄容器将参与方、类型、结果、Redis 扫描收进“更多筛选”；生效条件始终显示为可直接移除的标签 | 折叠不清空筛选，标签可移除；真实查询参数保持原有范围；宽容器仍直接展示筛选 |
| P2 | 可选 Docker Socket 位于必填认证之前，打断首次配置；等待连接提示与 Agent 连接能力不符 | Socket 移至高级连接设置；自定义值在折叠摘要中提示，校验错误强制展开；更新等待连接说明 | 折叠再展开保留草稿；基本信息后直接进入认证；页面打开仍不自动连接 |

## 全界面复审

以下按用户任务覆盖入口、详情、编辑与专业工作区；公共组件沿用 [界面规范](ui-style-guide.md) 和 [组件清单](ui-component-inventory.md)。保留代表本轮未发现足够依据要求改动，不代表每个组合状态均已穷举。

| 界面范围 | 评估与本轮决策 |
| --- | --- |
| 全局外壳、项目列表、环境与插件导航 | 保留三栏和可拖动分隔；实施窄窗投影、名称层级和状态文字，避免压缩后把名称挤到只剩一两个字 |
| 全局搜索、命令入口 | 保留标题栏入口和键盘快捷键；补充上下文组合检索，无须增加另一套搜索界面 |
| 项目概览、项目创建/重命名/删除 | 摘要计数与环境入口清楚，保留；删除继续走有范围说明的确认流程 |
| 环境详情、环境设置、排序与删除 | 保留概览、类型标记和独立展开/选择；长名称用截断加完整提示，导航窄栏调整类型标记位置 |
| 插件详情、名称与元数据、权限设置 | 保留专业插件差异、权限范围和修改入口；配置与连接状态分开表达 |
| 插件新增/连接编辑、凭据查看与迁移 | 优先展示基本目标和认证，再显示高级连接设置；保存、检查连接、取消与未保存保护保留 |
| 连接进度、错误诊断、主机密钥确认 | 保留明确重试和诊断详情；修正连接说明，不改信任与连接行为 |
| 运维说明 | 保留阅读/编辑、保存和冲突恢复；长文由内容区域滚动，不添加额外常驻工具条 |
| 快捷问题 | 保留分类、编辑与复制流程；本轮不增加会削弱问题正文的装饰卡片 |
| 操作确认、消息中心 | 范围、目标、风险和完整内容比列表密度更重要。旧提交基线的消息浮层偏窄；主工作区已有扩展浮层与确认跟进的并行改动，复查其宽版效果后，本分支不复制该改动 |
| 环境/插件操作记录 | 实施渐进展示筛选和可移除条件，继续保留时间分组、执行过程、错误说明、清除确认与加载更多 |
| Server 文件目录、文件查看/编辑/差异 | 保留目录/内容分栏、标签、编辑状态和差异查看；不把文件路径统一改成界面字体 |
| Server 终端、日志、传输、指标 | 保留专用字符网格、搜索、任务进度与状态栏；与普通详情页采用不同密度有合理依据 |
| Docker 列表、容器详情、日志 | 保留对象选择到详情的结构及中文状态；Socket 配置从通用认证首屏移到高级设置 |
| MySQL 数据库目录、SQL 文档、结果表格、数据编辑与事务 | 保留面向高密度数据的布局、等宽 SQL、多文档和底栏反馈；不通过放大所有控件减少有效结果面积 |
| Redis 范围、键树、值编辑、TTL 与写入确认 | 保留类型和范围提示。键树全键名有重复前缀问题，但完整键名也帮助确认实际对象；本轮保留，后续应结合复制和选中行为验证缩写方案 |
| 云配置、仓库、项目同步、备份/历史/恢复 | 保留现有状态与冲突摘要；“本地创建”和“云端获取”的入口层级可继续简化，但优先级低于导航与表单 |
| 配置、Codex 集成、主题、软件更新、关于 | 保留集中入口、版本来源和深浅主题；小型辅助字只在角标等非决策内容中使用，风险和操作说明不应继续缩小 |
| 公共按钮、菜单、浮层、空/加载/失败状态 | 沿用现有公共组件与语义色；针对本次窄栏图标操作保留提示、焦点及可访问名称，筛选折叠提供 `aria-expanded`/`aria-controls` |

## 验证方式

所有截图及运行数据使用模拟项目、环境、插件和临时目录，没有连接真实基础设施。截图放在仓库之外：`/tmp/runbook-ui-experience-review/`。覆盖 960×640 与 1280×820、深浅主题、长名称、错误/受阻状态和宽度恢复。

专项 Electron 测试入口：

```sh
corepack pnpm run build:renderer
corepack pnpm exec electron scripts/ui-react-foundation-smoke.cjs --experience-review-only
```

本机缺少 Corepack，实际检查通过已安装的 Node、TypeScript、Vite 和 Electron 直接执行相同底层命令，不修改锁文件或依赖版本。

### 已通过

- 语法检查：444 个源文件、脚本和测试文件；TypeScript 检查通过。
- Vite 生产构建通过，保留原有大分块提示。
- 全量单测：2016 项，2014 通过、2 跳过、0 失败。初次沙箱内运行因回环监听和路由查询被禁止失败，允许本地模拟服务后重跑得到此结果。
- 最终 renderer 单测：272 项全部通过。
- 最终 UI 体验专项：窗口压缩/恢复、窄窗折叠后恢复首选宽度、无横向溢出、上下文搜索、可见异常状态、筛选展开/收起/移除、实际筛选请求、高级字段草稿均通过；无写入调用、外部请求及 renderer 错误。
- 完整 UI 分项中的 MySQL 编辑、Docker、Redis、云配置通过。
- 基础 UI 回归已走过新布局、125%/150%/200% 缩放、深浅主题、资源行几何、环境展开与选择、项目栏折叠等检查，随后在下述焦点检查停止。

### 尚未通过的完整 UI 检查
