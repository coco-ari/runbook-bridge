# 工作区固定操作规范

适用范围：SSH（含 Docker 标签）、MySQL、Redis 全窗口工作区。

## 位置与图标

连接标题栏提供返回详情、工作区列表、连接配置、应用设置、连接操作和关闭工作区入口。应用设置管理主题、云同步等全局选项；连接配置编辑当前插件。断开后原位置改为重新连接，连接进行中可取消当前连接计划。内容标签栏统一高 40px，左侧为标签和新增入口，最右侧为独立的布局操作组。标签过多时只滚动标签列表，布局操作组不随之滚动。

| 操作 | 固定位置 | 图标 | 提示文字 |
| --- | --- | --- | --- |
| 最大化内容 | 标签栏最右侧 | ArrowsOut | 最大化工作区 |
| 恢复侧栏与分栏 | 同一个按钮、同一个位置 | ArrowsIn | 恢复分栏 |
| 收起/展开 SQL 编辑器 | 主布局按钮左侧 | CaretUp / CaretDown | 收起 / 展开 SQL 编辑器 |
| 新增标签 | 标签列表之后、布局组之前 | Plus | 新建 SQL 查询 / 新增终端 |
| 关闭标签 | 标签内部尾部 | X | 关闭 + 标签名称 |
| 刷新内容 | 所属内容工具栏 | ArrowClockwise | 刷新 + 对象名称 |

布局按钮的点击区域为 32×32px，图标为 16×16px，右边距为 8px。使用统一组件管理位置、图标、可访问名称、提示和展开状态。局部展开/收起使用方向箭头，全区最大化/恢复使用四向箭头，避免一个图标承担不同层级的操作。

## 行为

- SSH 收起资源侧栏和文件预览，保留资源切换栏、终端会话与 Docker 标签；恢复时显示分栏。按钮放在标签栏，关闭全部终端或打开 Docker 时依旧可用。
- MySQL 收起表列表，SQL 编辑器的展开状态独立保留；查看数据表时保留编辑器开关位置并禁用。
- Redis 收起 Key 列表，空白工作区也保留同一按钮；移除左侧临时菜单图标和浏览菜单中的重复收起入口。
- 切换布局保留标签、选中项和当前数据。按钮不卸载，点击后焦点保留，Enter/Space 使用原生按钮行为。
- 原有侧栏拖动、双击重置、搜索快捷键和连接安全边界保持现有约定。

## 验证

`scripts/workspace-layout-ui.cjs` 在各工作区的 Electron fixture 中复用，检查真实鼠标点击、Enter 恢复、点击区域与右侧位置、受控面板、焦点、标签状态和侧栏宽度恢复。Redis 覆盖空内容和 700px 窄窗口；SSH/Docker 覆盖切换容器后的布局控制。

运行 `corepack pnpm run check`、`corepack pnpm test`、`corepack pnpm run test:ui`，以及 `test:ui:server-workspace`、`test:ui:database`、`test:ui:redis`、`test:ui:docker`。全部使用模拟数据，不连接真实基础设施。

## 工作区切换与内容保护

左侧工作台和各工作区页头均提供“工作区”入口，显示已保留会话数量。列表按项目、环境、插件标注连接状态和待处理草稿，可继续或关闭指定会话；切换与离线继续均不自动连接。关闭复用该工作区已有的草稿、事务和任务保护。MySQL 保持最多一个工作区；切换项目、环境或插件保留其内容，打开另一数据库前需从列表明确关闭原工作区，不能自动替换草稿。

MySQL 表数据的“放弃全部更改”及运维说明的“放弃编辑”在有改动时要求明确确认；快捷提问库将内容追加到已有输入末尾。SQL 标签关闭和运维说明版本冲突处理保持原有行为。带禁用说明的按钮可通过鼠标悬停或键盘聚焦外层提示查看原因。

服务器终端已结束但服务器仍连接时显示“重新打开终端”；服务器离线时显示“连接并打开终端”。这些操作建立新会话，保留已显示历史，不重放旧命令。

全局搜索打开时按需补齐超过环境预览数量的本地插件列表，最多并发读取三个环境。读取失败时显示搜索不完整并提供重试，不连接远程服务。应用设置中的只读状态检测不会阻止返回，写入操作仍沿用原有保护。
