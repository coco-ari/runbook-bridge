# 服务器工作区设计与安全边界

> 日期：2026-09-12
>
> 状态：已采用。
>
> 范围：桌面 Server 插件详情中的人工终端、目录浏览、只读预览和文件上传；不增加 MCP 工具。

## 入口与交互

服务器详情的连接操作区提供「打开工作区」。未连接时不能打开，用户先主动连接服务器。已有工作区时显示「继续工作区」。打开后使用窗口完整内容区，暂时收起项目与环境导航：左侧目录树、右侧连续终端、底部传输任务，文件只读预览按需展开。

文件树按需加载，路径可直接输入，目录和终端分别维护自己的浏览位置。同一父目录下默认文件夹在前、文件在后，组内按名称自然排序（如 `2` 在 `10` 前），Windows 和 macOS 使用相同规则。分页前先固定普通目录优先的快照顺序；已加载的目录软链接在类型解析完成后归入界面的文件夹组，未解析链接不提前假定为目录。展示排序不改写分页缓存，避免元数据补齐或继续加载时漏项、重复，也不增加全目录链接扫描。文件面板默认宽 320 像素，使用实心黄色文件夹、按类型区分的文件图标、14 像素字号和 32 像素紧凑行高，不提供密度切换。工具栏集中收起目录、隐藏文件、刷新与上传，路径默认呈现可点击面包屑，单击右侧空白或编辑按钮切换为输入框；Enter 定位文件或目录，Escape 取消。所有定位入口都保留以 `/` 为根的目录树，展开祖先链并滚动、高亮目标，定位文件只选中、不自动预览。目录项使用所在目录与文件名组成的自身路径作为身份，符号链接不使用目标路径作为行标识；加载提示与文件行也使用不同的标识前缀，避免展开、刷新时重复节点造成重影。桌面目录项通过 `linkTarget` 和 `linkTargetType` 显示目标路径及类型：目录链接使用带链接角标的文件夹图标并可展开，普通文件链接使用文件图标并可只读预览；失效或特殊文件链接不可打开。界面保留链接自身路径，每条展开分支按真实目录路径检测循环，避免 `X11 → .` 无限展开。浏览目录不会向终端发送命令。文件单击只选中，双击打开只读预览；键盘 Enter 打开预览，空格只选中。文件夹仍单击展开或收起。拖动文件或文件夹到当前终端，在光标处插入经过 Shell 引号转义的完整路径，不附加 `cd` 或回车，保留空格、中文及单引号。符号链接插入链接自身的完整路径。移除原「填入终端」按钮。拖拽仅在当前工作区的活动终端就绪时生效，取消或断线后不会补发；拖动不会打开预览、展开目录或改变上传目标。上传目标在开始前展示并固定，不随文件树导航变化。

多行粘贴先预览，确认一次后整段发送，保留缩进、空行及终端括号粘贴协议；未启用括号粘贴的 Shell 可能立即执行换行。支持复制/粘贴按钮、右键菜单、Windows 的 Ctrl+V / Ctrl+Shift+V 与 Ctrl+Shift+C、macOS 的 Cmd+C/V；Ctrl+C 保留中断功能。系统剪贴板只通过绑定桌面窗口和终端会话的 serverTerminalClipboard 接口访问，不对 MCP 开放。切换标签、断线或关闭后丢弃迟到的粘贴结果，远端 OSC 52 仍被拦截。

分栏可调整，终端可独占工作区；统一使用紧凑布局，页头提供与数据库一致的“配置”入口，进入配置页面选择浅色、深色和跟随系统主题，或操作云配置，返回时保留工作区；返回、断开、关闭、最大化、刷新以及标签新增和关闭按钮使用共用控件。滚动终端查看历史时，新输出不强制抢回底部。长文件名、路径和连接信息允许截断显示及查看完整内容，不能挤掉主要操作。

「返回详情」只切换页面，保留同一终端会话、终端缓冲、文件树状态和正在进行的传输。「结束会话」结束人工终端，不断开服务器，也不取消其他上传。「断开连接」结束终端并中断传输，可恢复的上传任务在内存保留 30 分钟。应用退出或所属 Renderer 被销毁时释放会话资源；应用重启不自动恢复远程连接或补发命令。

## 当前终端目录定位

工具栏「定位终端当前目录」只在活动标签会话就绪时启用。点击后按该会话读取目录，再复用目录树定位；切换标签、关闭、断线、隐藏工作区或开始其他导航后，迟到结果不能改变选择。不向人工终端写入 `pwd` 或回车。

桌面专用 `serverTerminalWorkingDirectory({ projectId, environmentId, pluginInstanceId, sessionId })` 返回 `{ path }`，不接受进程号、路径或命令。主进程核对 owner、作用域、连接 generation 和连接配置，完成后再次核对；同会话并发查询合并，关闭会话会取消查询。MCP 不开放此接口。

已识别的 bash、zsh、sh、dash、ash、ksh、ksh93 在新建终端时使用一次性随机帧记录登录 Shell 的进程号，关闭自动目录配色时仍可记录。点击定位时复用同一 SSH 连接的独立非 PTY 通道，仅执行固定的 `readlink /proc/<登录 Shell 进程号>/cwd` 查询，超时 3 秒、输出总量上限 4097 字节；严格验证 UTF-8 绝对路径，不返回远端错误内容或记录路径日志。不放宽文件预览及 MCP 对特殊文件的限制。

此方式需要 Linux 的 procfs 和查询该 Shell 进程的权限；不支持的 Shell、系统或权限受限时显示无法读取目录。定位的是该标签最初登录 Shell 的实际目录；在嵌套 Shell、`su`、容器或 tmux 内切换的目录不由此接口推断，可手动输入路径定位。

## 终端自动恢复

客户端运行期间，意外断线后复用现有 SSH 重试，在原标签中建立新会话；保留有界历史文字，清理旧控制状态，不重放输入。主动断开期间不重试，用户重新连接后恢复原活动终端；主动退出、结束会话、停止恢复和配置失效不恢复。工作区提供真实重试进度和直接重试入口，停止当前标签恢复不会关闭共享连接。详细交互、桌面 IPC 和验证范围见 [终端自动重连](terminal-auto-reconnect.md)。

## 人工会话与 Agent 权限

本次是明确的安全设计扩展：桌面用户可以主动打开连续人工 PTY，会话中的键盘输入直接发送给远程 Shell，按 SSH 登录账号的权限执行。它采用人工会话级授权，不套用 Agent 的逐命令 `command-policy` 或一次性 Shell 确认。否则 `vim`、`top`、密码提示和交互式程序无法正常工作。

人工会话 API 仅在桌面 IPC 边界提供。MCP 不增加打开会话、读取终端、发送按键或接管人工会话的能力；已有 Agent Shell、上传和其他变更仍经过原来的作用域、短期上下文、操作门禁和单次确认。人工打开工作区不能给 Agent 产生额外权限，也不能被 Agent 的批准 Token 替代。

主进程为人工会话绑定：

- 创建它的 Renderer owner，不能由另一个窗口读写或关闭。
- 精确的 `projectId`、`environmentId`、`pluginInstanceId`，且目标必须是已经连接的 Server。
- 当前 SSH generation 与 `pluginConnectionFingerprint`，连接换代或实际连接配置变化后旧会话和请求失效。

输入、尺寸调整、输出确认、结束会话和文件任务都必须核对所属对象。异步打开完成时再次核对 owner、作用域与连接，防止用户已经断开或切换配置后又挂入旧 channel。页面跳转仅隐藏工作区；Renderer 销毁、连接失效和所属资源失效必须触发资源清理。修改插件显示名称或 Agent 策略只更新一般 revision，不关闭人工终端；改变连接配置或连接依赖的提交，在生效前关闭受影响工作区，删除环境或插件也使其会话失效。上传预检仍严格绑定其准备时的 revision，在启动与提交前复核，不复用人工终端较宽的元信息变更策略。

所有应用管理的密码、私钥口令、代理凭据和解密值继续留在既有凭据流程中。终端输入输出、命令历史、远程文件预览和浏览目录缓存只存在内存中，不写入工作区 YAML、自动保存文件或应用日志。审计仅记录必要的会话起止和上传任务元数据，不记录按键或终端全文。该约束不改变远程 Shell 自己保存历史的行为，也不禁止用户主动上传到服务器的文件写入目标路径。

终端输出和文件名均作为不可信文本渲染。保持现有 CSP、sandbox、context isolation 和禁用 Node integration；不加载 CDN、远程脚本或字体，不把输出写入 HTML。远端控制序列不得自动执行本地程序、读取剪贴板或打开任意链接。

## 性能与流控

服务器工作区按需加载，xterm 不进入初始页面主包。终端输出以有界字节块传输，xterm 实例和 I/O 缓冲独立于 React 页面状态；不会为每个输出块触发整页重新渲染。借鉴 [xterm.js 官方流控机制](https://xtermjs.org/docs/guides/flowcontrol/)，当前采用串行拉取：Renderer 等待本批 `terminal.write` 完成回调后才请求下一批，下一次读取相当于上一批已经消费的确认，不另外开放可任意提交字节数的 ACK 接口。

主进程每次最多返回 64 KiB 原始字节，同一终端只允许一个挂起读取；队列到 512 KiB 高水位时暂停 SSH channel，排空至 128 KiB 低水位时恢复。该水位是暂停阈值，不是整个进程的内存上限；还需计入 SSH 内部缓冲和正在交付的一批数据。终端历史保留 5000 行，主进程待发送输入限制为 256 KiB；Renderer 输入队列与单次粘贴按真实 UTF-8 字节计量，限制为 64 KiB，二进制鼠标事件按字节原样传输。UTF-8 跨块解码交给终端处理，不能按 JavaScript 字符数截断输出。用户返回详情时仍保留消费链路，不能让隐藏页面形成无限输出队列。

容器变化通过 `ResizeObserver` 合并处理，将有效行列同步给远端 resize。隐藏期间不能上报零行零列，恢复显示后重新测量。目录使用后端已有的有界分页，每次读取 200 条，按展开节点加载；单个目录每个 UI 批次最多展开 2000 条，仍有后续游标时可点击「查看下一批」替换当前批次，也可返回上一批。后端单次目录读取最多保留 10000 条，达到该上限且没有后续游标时明确显示读取上限提示。目录导航优先复用当前工作区内存中的列表，保留完整父级、同级及已有展开分支。面包屑同步选中目录，定位文件时显示其父目录；输入路径、面包屑、上级按钮、收藏、传输定位和终端目录定位共用展开、高亮及虚拟列表滚动流程，树根始终为 `/`。缺少缓存时按有界分页读取，旧分页没有目标时从第一页查找；定位期间临时保留一份同等上限的原视图缓存，失败恢复原选择及滚动位置，完成或取消后释放；路径超过 31 层或定位所需目录被缓存上限淘汰时停止并提示，避免反复读取。双击文件始终实时读取，结构化路径不存在、目标类型变化或链接映射变化错误会清除相关缓存并刷新父目录，父目录失效时再核对上一级。权限或网络错误保留缓存及错误提示；手动刷新和上传完成仍更新相关目录。断开连接和关闭工作区清理目录缓存，不持久化远程内容。缓存按最近访问顺序，以 32 个目录或共 5000 个条目为淘汰阈值，保护当前根目录、正在读取的目录及本次更新目录；已淘汰目录可重新读取。虚拟行高固定为 32 像素，与紧凑布局一致。过期目录响应不得覆盖用户后来选中的目录。上传进度通过任务快照轮询合并更新，避免每个文件块触发界面刷新。

这些是实现约束，不是已测得的吞吐或延迟承诺。性能验收需检查高速输出时输入可响应、缓冲有界、大目录滚动和传输同时进行时的界面表现。

## 上传流程与初版范围

初版支持每次选择 **1–20 个**普通文件上传，单文件最大 **500 MiB**，应用内同时进行最多 **2 个**传输。每个窗口最多同时保留 **8 个**活动人工终端，允许同一服务器打开多个独立标签；每个标签持有自己的 PTY、输入队列、输出缓冲、尺寸和粘贴队列，后台标签继续有界消费输出。桌面 serverTerminalOpen 增加可选 tabId（1–80 个字母、数字、下划线或连字符），同 owner/作用域/标签的并发打开复用一个会话，省略时使用兼容的默认标签；MCP 接口不变。关闭标签只结束对应终端。文件预览最多同时保留 **12 个**标签，每个文件最多 256 KiB；标签切换保留内容与滚动位置，点击树中的文件或刷新按钮重新读取，关闭后迟到响应不会恢复标签。同名文件显示父目录区分。文件树支持目录浏览和只读文件预览，单次预览最多读取 256 KiB 并提示截断；不提供文件编辑保存、目录递归上传、断点续传或应用重启后的任务恢复。

用户选择文件后，主进程建立与 owner、服务器和目标路径绑定的待上传任务。预检凭证有效期为 5 分钟，完整执行参数只留在主进程；桌面预检结果增加所选文件的 `localPath`，仅用于展示与复制，不进入 MCP 或审计。Renderer 确认时仍仅提交预检凭证与覆盖意图，不传回本地路径、哈希或状态前置条件。确认页以「本地完整文件路径 → 服务器实际目标目录」为主体，逐项显示大小，两端路径均可一键复制；长路径完整换行，多文件有界滚动。服务器名称、环境和连接身份缩为一行，只有同名文件才显示覆盖提示。上传目标在选择文件时固定，确认页不再提供更换目录或目录浏览；桌面 `serverWorkspaceReviseUpload` 仅提交 `reviewId` 和原文件名子集，用于移除或重新检查；不接受目标目录字段，链接改向返回 `WORKSPACE_PATH_CHANGED`。只移除文件且原检查成功、未过期时，主进程直接缩小已校验集合，不读取文件内容或查询远端，原子撤销旧凭证并签发剩余文件的新凭证，原有效期不延长。失败、过期或主动重新检查时，从原生选择保存的路径重新计算文件与目标状态。只有完整检查成功或有效结果的严格子集可以签发新凭证；失败结果不能授权上传。移除最后一个文件撤销预检。Renderer 在每次修改后清除覆盖勾选，重新检查、重新选择文件均有明确入口；真正执行前重新核对本地文件与远端目标。用户在确认后导航到其他目录，不改变这些任务参数。任务清单始终展示各任务的固定目标、已传字节、百分比和状态，完成后可定位并高亮目录树中的文件；工具栏将当前浏览位置标记为「新上传目标」，避免与已有任务混淆。

上传复用 `src/server-operations.mjs` 和 `src/ssh-broker.mjs` 的预检与执行基础；桌面分块传输及续传校验位于 `src/server-upload-transfer.mjs`，恢复确认位于 `src/server-upload-resumes.mjs`：

1. 只接收本地普通文件，拒绝符号链接和超限文件。
2. 绑定规范化本地路径、大小、mtime、SHA256、远端规范化目标、覆盖意图及目标状态；参数变化必须重新准备和确认。
3. 在目标旁创建随机临时文件，传输期间不把未完成内容发布成目标文件。
4. 传输过程中计算实际发送内容的哈希；完成后核对本地文件状态、内容哈希和远端临时文件大小。在提交前再次校验 owner、作用域、配置 revision、SSH generation、父目录 canonical 路径及目标状态，成功重命名后才标记「完成」。字节进度达到 100% 仍可能处于「校验中」。
5. 取消只影响该上传任务；断线标记中断，不自动重试、覆盖或删除不确定的远端结果。临时文件清理须使用任务持有的确切路径，不能扩大删除范围。排队取消和窗口/作用域关闭也清理内部参数并记录终止审计，不能只把任务从界面移除。

根据用户要求，人工桌面浏览增加符号链接导航；这是仅限桌面人工 API 的安全设计扩展，Agent/MCP 的符号链接目录遍历限制保持原样。人工访问先解析真实路径，再核对最终目标是普通目录或文件，保留读取数量与字节上限，拒绝解析失败、循环及特殊文件读取。读取前后重新解析逻辑路径，目标变化时丢弃结果；分页目标变化时清理旧目录缓存。每页最多 8 个并发链接元数据请求，共用只读 SFTP 会话，返回 `canonicalPath` 供界面识别真实目录。上传预检同时绑定逻辑目录 `sourcePath` 与实际目标目录，确认界面明确展示实际目录；确认、任务开始和最终提交前重新验证链接映射。上传仍使用原有本地文件哈希、远端状态前置条件及临时文件提交机制。目录不是 Shell 白名单；人工终端和文件浏览各自遵循明确的权限模型，不能用 UI 限制宣称 SSH 用户权限已经降低。

中断后重新连接，点击「继续上传」生成绑定当前连接的新确认，校验源文件与已传前缀后恢复原任务，最多三次。应用或所属窗口关闭后不恢复；配置、主机身份或路径变化时拒绝。分块并发、恢复成本及可重现性能测试详见 [续传与速度优化](upload-resume-feasibility.md)。

后台预处理的生命周期、风险评估及桌面接口详见 [上传后台预处理](upload-preprocessing-design.md)。选择文件后先返回路径和大小，检查期间显示阶段及进度、允许取消；远端批量检查复用一个 SFTP 会话，本地哈希完成后以第二个会话复核目录，再签发五分钟有效的上传凭证。


## 终端搜索与常用目录

- 终端面板内按 Windows/Linux 的 Ctrl+F、Mac 的 Command+F 打开搜索栏，不提供工具栏搜索按钮；再次按快捷键聚焦并选中已有关键词。Enter / Shift+Enter 切换下一处/上一处，Esc 关闭并返回终端输入。Windows/Linux 的 Ctrl+F 用于搜索，不再发送给 Shell；Mac 的 Control+F 仍保留 Shell 行编辑行为。
- 搜索复用官方 @xterm/addon-search 0.16.0，只在当前终端已加载缓冲区中查找普通文本，支持中文、折行匹配、区分大小写及深浅主题高亮。查询最长 256 字符，最多高亮 1000 处；不扫描服务器日志文件、不发送命令。各标签独立，搜索词仅保存在界面内存；断线仍可搜索历史，重连沿用原终端组件。
- 官方搜索扩展需要 xterm 的装饰 API，因此只在 Renderer 的 xterm 实例启用 allowProposedApi；不改变 SSH、桌面 IPC 或 Agent 权限。搜索参数或主题变化时主动清除扩展缓存，确保匹配数量和高亮更新。
- 目录工具栏星标打开「常用目录」。可收藏/取消收藏当前目录、打开收藏和单独移除收藏。收藏按项目、环境及服务器标识隔离，每台服务器最多 20 个，只保存本机路径列表，重启后保留。点击收藏复用目录定位流程，从 / 展开祖先路径并打开、高亮目标目录，保留同级与已有展开分支；优先使用短期缓存，不把收藏目录设为树根。分页位置未包含目标时重新定位，失效目录或循环链接显示提示；路径层级及缓存超限时停止定位并提示，以维持目录缓存上限。
- 收藏点击复用已有目录导航及读取校验，目录不存在或权限不足沿用原错误提示；断开时可查看、移除收藏，重新连接后才可跳转。收藏不触发自动连接，不修改已有传输任务的固定目标。
- 本地存储不可用、已满或数据损坏时显示错误，不将失败显示为保存成功。收藏保存原路径，跳转保留目录名空格，并沿用既有目录规范化与校验；持久化和跨作用域边界见 test/renderer-directory-bookmarks.test.mjs，真实渲染回归并入服务器工作区 UI smoke。

## 终端分类配色

复用既有 xterm.js 和 ssh2，继续使用 xterm-256color PTY；完善深浅主题的 16 色 ANSI 调色板和最低文本对比度，保留标准 256 色、真彩色序列支持。不通过文件名匹配篡改任意终端输出，也不引入新的生产依赖。参考 [xterm.js 调色板](https://xtermjs.org/docs/api/terminal/interfaces/itheme/)及 [GNU Coreutils 的 ls/dircolors](https://www.gnu.org/software/coreutils/manual/coreutils.html)。

目录分类色由远端命令产生。新建人工终端默认自动执行主进程内置的固定配色配置，为 GNU/BSD ls 设置目录、链接、可执行文件的颜色及 ll 别名。仅在新 PTY 创建、窗口与连接仍有效时发送一次，收到专用完成标记前不接受人工输入；复用标签与返回工作区不会再次执行。初始化输出在主进程隔离，收到每个会话独立的随机完成标记后才开始转发普通终端字节；标记支持跨包解析，仅保留有限尾部，不依赖提示符或固定延时。15 秒内未完成或初始化输出超限会结束会话并提示关闭自动配色后重试；不会把启动脚本写入 Renderer 的回滚缓冲，也不会过滤初始化完成后的用户命令。设置仅影响当前会话，不修改服务器配置文件。

每条 SSH 连接使用有界只读探测识别登录 Shell（上限 1.5 秒、4 KiB），支持 Bash/Zsh/sh/dash/ash/ksh；未知 Shell、探测失败或额外输出均跳过自动设置。探测结果只用于判断，不拼接进命令。配置根据 GNU ls 能力或 BSD 系统类型选择语法。「目录配色」中的自动开关默认开启，本地只保存布尔偏好，仅影响之后新建的终端；Renderer 不可传入任意启动脚本。初始化沿用人工终端的取消、背压和输入超时边界，不扩展 Agent/MCP 权限。

工具栏同时保留 Linux/GNU 与 macOS/BSD 手动设置：用户先回到空白 Shell 提示符，点击「填入配色命令」后按 Enter 生效。手动入口不自动发送回车，不解析远端提示符猜测执行时机。

## 目录读取性能与缓存

参考 [WinSCP 的目录缓存](https://winscp.net/eng/docs/directory_cache)和[链接解析开销说明](https://winscp.net/eng/docs/ui_login_directories)，复用现有 ssh2/SFTP 实现，不增加生产依赖。目录名和普通文件类型直接来自 [READDIR 属性](https://github.com/mscdex/ssh2/blob/master/SFTP.md)，不逐项请求 STAT，也不使用 Shell 输出解析目录。

- 首次读取在一个 SFTP 通道内完成目录映射校验与基础枚举；目录句柄最多同时有 4 个 READDIR 请求。基础列表读取上限仍为 10,000 项，排序后每页 200 项。首屏仍需完成这一次有界基础枚举，以保持全目录稳定排序；不会等待软链接目标逐个解析。
- 主进程保留最多 32 个目录、合计 20,000 项的内存快照，以最近使用顺序淘汰。分页复用同一份快照，并实时检查目录链接映射，避免每页重新扫描；已打开目录的返回与展开继续使用 Renderer 缓存，无须网络请求。快照不落盘，不跨窗口、插件、配置修订或 SSH 连接代次复用。
- 桌面 list-directory IPC 增加可选 deferLinks、snapshotId、resolveLinks；返回 snapshotId 和 metadataPending。Renderer 首次请求 deferLinks=true，收到基础列表后显示，再按快照和分页位置请求 resolveLinks=true。后台最多处理两个页面，每页最多 8 个链接查询，查询结果按路径原位合并。未解析链接显示“读取中”，点击后待解析完成继续打开；传输失败显示重试，不误报为断链。Agent/MCP 契约保持不变。
- 明确刷新替换对应快照；快照淘汰后分页自动重新读取首批，避免混合新旧列表。断连、作用域关闭或窗口销毁清理缓存并中止相关读取，迟到响应不能恢复旧快照。单次操作结束即释放 SFTP 通道，不长期持有空闲会话。
- 文件预览和上传仍按既有实时路径与状态校验执行，目录缓存不能作为写入授权或目标状态依据。外部修改可手动刷新，打开失效文件时沿用局部刷新行为。

回归覆盖慢链接不阻塞首屏、分页只扫描一次、同页并发合并、缓存隔离与淘汰、刷新/关闭竞态、连接错误不误报断链，以及真实本地 SFTP 的四请求流水线、EOF 清理和无重复无遗漏。Electron 专项验证基础列表先出现、待解析链接点击后展开及行高和排序保持稳定。协议测试中的延迟对比使用 650 个测试文件、每个 READDIR 响应人为延迟 15 ms；该结果用于比较请求机制，不代表生产服务器的速度承诺。

### 上传进度与超时

上传进度按 SSH2 的服务器确认写入量统计，显示最近约五秒的速度与预计剩余时间；检查源文件、最终校验及完成阶段不显示传输估算。五秒无新增确认时显示等待服务器响应。上传连续 90 秒没有确认进展会中止；总时限按文件大小和 16 KiB/s 的保守速率估算，加两分钟开销，至少十分钟、最多十二小时。取消、源文件内容校验、目标状态复核和提交前作用域检查继续生效。

当前 preload 接口数量为 97，包含 Docker 读取、传输和文件菜单接口；MCP 共 40 个工具。新增 36px 图标资源栏、混合内容标签和 Docker 只读功能，详见 [Docker 工作区设计](docker-workspace-design.md)。上文 84/36 的验证记录对应此前版本。

应用运行期间的续传已接入桌面上传，重新连接后手动确认继续；MCP 上传不提供恢复接口。性能证据与未覆盖范围见 [上传续传与速度优化](upload-resume-feasibility.md)。

### 粘贴高亮与中文可读性

启用新建终端自动配色时，在支持活动区域自定义颜色的 Bash/Readline 中使用深青色背景、浅色文字显示待执行粘贴内容。使用原生 `active-region-start-color` / `active-region-end-color`，只设置当前会话，不写入 `.inputrc` 或 Shell 配置文件，也不关闭括号粘贴。旧版 Readline 或其他 Shell 保持原行为。已打开的会话可通过「目录配色 → 填入配色命令」，在空白提示符按 Enter 应用。

终端补充中文无衬线字体回退，多行预览使用 14 px 字号；鼠标选区显式设置前景色和失焦背景，避免复制按钮获取焦点后文字难以辨认。真实 Bash 回归验证待执行高亮和 Enter 前不执行；Electron 专项检查暗亮主题的高亮对比度至少 7:1，并确认 ANSI 目录颜色与多行输入行为保留。官方变量说明见 [Readline 文档](https://www.gnu.org/software/bash/manual/html_node/Readline-Init-File-Syntax.html)。

## 顶部资源状态条

- Linux 服务器工作区页头显示 CPU 使用率、内存使用量和本地磁盘用量。采用终端状态行样式：小写 cpu / mem / disk 标签、等宽数字、细竖线分组，不显示进度条。宽窗口并排显示内存和磁盘已用 / 总容量，悬停或键盘聚焦可查看完整详情，深浅主题分别适配；80% 以上使用警示色，90% 以上使用危险色。颜色仅作提示，不触发通知。空间不足时收起辅助信息，保留 cpu / mem / disk 与百分比；长挂载路径省略显示，完整路径保留在悬停详情与无障碍标签中。
- CPU 和内存通常每 5 秒采样，本地磁盘每 30 秒采样。CPU 使用两次 /proc/stat 累积计数的差值，去除 idle 和 iowait，guest 不重复计入总数；初次进入、暂停后恢复或连接更新时先建立基线，约 1 秒后补采得到使用率，再恢复 5 秒间隔。前端使用后台返回的剩余等待时间调度，提前到达的请求不会额外等待一个完整周期。内存使用 MemTotal − MemAvailable，不把可回收缓存全部当作已用。缺少字段显示暂不可用，不以零代替。
- 磁盘默认根分区 /，没有根分区时显示第一个有效本地挂载点，始终显示当前挂载路径。点击可查看或选择其他挂载点；选择仅保留在当前组件内存。过滤临时文件系统，最多保留 64 项并显示截断提示；不扫描目录大小，不统计远程文件系统。
- 返回详情、工作区隐藏、窗口最小化时停止请求并取消本窗口在途采集；关闭窗口、连接断开或配置失效时清理记录。重连后使用新连接重新采样，过期响应不能覆盖新值。读取失败保留最后一次有效值并标记“旧”和“数据已过期”，不反复弹出通知。不支持的服务器系统显示“仅支持 Linux”并停止轮询。
- 采集复用已有 ssh2 连接，以无 PTY 的独立短命令通道运行；不通过人工终端输入，不重新认证。每台服务器的系统与磁盘各共用一组采样，每类指标仅允许一个在途请求；两类使用独立通道与返回结果，内存读取完成即可显示，慢磁盘不会阻塞 CPU 首显或更新，迟到磁盘响应也不会覆盖系统新值。每个通道超时最多 3 秒并覆盖通道建立阶段，输出与错误合计最多 64 KiB；超时只关闭采集通道。磁盘失败不清空 CPU 和内存，主 SSH 连接与传输通道继续由原生命周期管理。
- 新增桌面只读 API serverWorkspaceMetrics / serverWorkspaceStopMetrics，读取接口仅接受项目、环境、插件作用域及可选 kind（system 或 disks，默认 system），响应增加 retryAfterMs 表示本类指标距离下次采样的剩余毫秒数；停止接口仅接受作用域。沿用 Renderer 来源校验、已连接 Server 校验及固定命令策略，不接收命令、路径或远程脚本，不改变现有 MCP 工具、上下文或确认机制。后台固定读取 Linux CPU/内存计数和本地 df 用量，不开放任意 /proc 文件读取。
- 开始采集前必须成功记录作用域审计；审计只记录开始、停止及状态变化，不记录指标、挂载路径或命令输出。指标仅在内存缓存，退出后清除。
